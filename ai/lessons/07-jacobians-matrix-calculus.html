Part 2 · Calculus

Jacobians & matrix calculus

A neural network is a pipeline of vector-to-vector functions ending in one number, the loss. The derivative of each stage is a matrix, the Jacobian. The chain rule becomes matrix multiplication, and doing that multiplication in the right order is the whole trick behind backpropagation.

By the end you can

  • Explain the Jacobian as the best local linear map of a vector function, and compute it.
  • Apply the multivariable chain rule as a product of Jacobians, checking dimensions as you go.
  • Derive gradients of $\mathbf w\cdot\mathbf x$, $A\mathbf x$, $\mathbf x^\top A\mathbf x$, $\|A\mathbf x-\mathbf b\|^2$ and of a loss with respect to a weight matrix, using the rule "the gradient has the shape of the parameter".
  • Derive the softmax Jacobian $\operatorname{diag}(\mathbf p) - \mathbf p\mathbf p^\top$.
  • Run a forward and backward pass through a small computation graph by hand, and explain why reverse mode (vector–Jacobian products) is the right choice for a scalar loss.

    1. The Jacobian: the derivative of a vector function

    Lesson 05 had $f:\mathbb{R}\to\mathbb{R}$, whose derivative is a number. Lesson 06 had $f:\mathbb{R}^n\to\mathbb{R}$, whose derivative is the gradient vector. Now take the general case $\mathbf f:\mathbb{R}^n\to\mathbb{R}^m$, with $n$ inputs and $m$ outputs, like a layer of a network. Each output $f_i$ has its own gradient. Stack those gradients as rows and you get the $m\times n$ Jacobian matrix:

    $$J = \frac{\partial\mathbf f}{\partial\mathbf x} = \begin{bmatrix} \partial f_1/\partial x_1 & \cdots & \partial f_1/\partial x_n\\ \vdots & & \vdots\\ \partial f_m/\partial x_1 & \cdots & \partial f_m/\partial x_n\end{bmatrix}, \qquad J_{ij} = \frac{\partial f_i}{\partial x_j}.$$

    Row $i$ says how output $i$ responds to every input. Column $j$ says how every output responds to input $j$. And the familiar linear approximation still holds, now with a matrix–vector product:

    $$\boxed{\;\mathbf f(\mathbf x + \mathbf d) \approx \mathbf f(\mathbf x) + J(\mathbf x)\,\mathbf d\;}$$

    Lesson 02 showed that a matrix is a linear map. So the Jacobian is the best linear map approximating $\mathbf f$ near $\mathbf x$. Zoom in on any smooth map, however curvy, and it looks like a matrix acting on the plane: grid squares become parallelograms. The determinant of $J$ is the local area scale factor (lesson 03).

    Try it: left, the input plane, with a small square neighbourhood around the draggable point. Right, the output plane under $\mathbf f(x,y) = (x + 0.6\sin y,\; y + 0.3x^2)$, zoomed in on $\mathbf f(\text{point})$. The orange curves are the true image of the little grid. The blue parallelogram is what the Jacobian alone predicts. Shrink the neighbourhood: the curved image straightens and snaps onto the parallelogram. Drag the point and watch $J$ (and its determinant, the area scale) change from place to place.
    Worked example: polar coordinates

    $\mathbf f(r,\theta) = (r\cos\theta,\; r\sin\theta)$. Differentiate each output by each input:

    $$J = \begin{bmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta\end{bmatrix}, \qquad \det J = r\cos^2\theta + r\sin^2\theta = r.$$

    The determinant $r$ is the familiar factor in $dA = r\,dr\,d\theta$: a small rectangle in $(r,\theta)$ maps to a patch $r$ times larger in area, because circles get longer as $r$ grows.

    2. The chain rule is matrix multiplication

    Compose $\mathbf u = \mathbf f(\mathbf x)$ (with $\mathbf f:\mathbb{R}^n\to\mathbb{R}^m$) and $\mathbf y = \mathbf g(\mathbf u)$ (with $\mathbf g:\mathbb{R}^m\to\mathbb{R}^k$). Each is approximately linear near the point. Linear maps compose by multiplying their matrices (lesson 03). So:

    $$\boxed{\;J_{\mathbf g\circ\mathbf f}(\mathbf x) = J_{\mathbf g}\big(\mathbf f(\mathbf x)\big)\;J_{\mathbf f}(\mathbf x)\;}\qquad (k\times n) = (k\times m)(m\times n).$$

    Derivation. $\mathbf g(\mathbf f(\mathbf x+\mathbf d)) \approx \mathbf g(\mathbf f(\mathbf x) + J_{\mathbf f}\mathbf d) \approx \mathbf g(\mathbf f(\mathbf x)) + J_{\mathbf g}J_{\mathbf f}\,\mathbf d$. $\blacksquare$ It's lesson 05's "rates multiply", except the rates are now matrices. As before, the outer Jacobian is evaluated at the inner value $\mathbf u = \mathbf f(\mathbf x)$.

    Written entry by entry, the matrix product is a sum over the intermediate variables:

    $$\frac{\partial y_i}{\partial x_j} = \sum_{l=1}^{m}\frac{\partial y_i}{\partial u_l}\,\frac{\partial u_l}{\partial x_j}.$$

    Read it as: add up the effect along every path from $x_j$ to $y_i$. If $x_j$ influences $y_i$ through three different intermediates, all three contributions add. This "sum over paths" is what makes the backward pass in section 6 work when one value feeds several later ones.

    Use the dimensions as a spell-checker. $J_{\mathbf g}J_{\mathbf f}$ is $(k\times m)(m\times n)$, which works. $J_{\mathbf f}J_{\mathbf g}$ would be $(m\times n)(k\times m)$, which doesn't even multiply unless $n = k$. Most matrix-calculus mistakes show up as a shape mismatch.

    3. Gradients with respect to vectors

    Machine learning mostly needs one special case: a scalar loss $L$ of a vector or matrix. Its Jacobian is a single row ($1\times n$). By convention we store it as a column with the same shape as $\mathbf x$, and call it the gradient $\nabla_{\mathbf x}L$ (lesson 06). The cleanest way to find one is the differential trick: perturb $\mathbf x$ by $d\mathbf x$, expand $dL$ to first order, and arrange it as $dL = \mathbf g\cdot d\mathbf x$. Then $\mathbf g = \nabla_{\mathbf x}L$, since that's the linear approximation from lesson 06.

    FunctionFirst-order changeDerivative
    $L = \mathbf w\cdot\mathbf x$$dL = \mathbf w\cdot d\mathbf x$$\nabla_{\mathbf x}L = \mathbf w$ (and $\nabla_{\mathbf w}L = \mathbf x$)
    $\mathbf y = A\mathbf x$$d\mathbf y = A\,d\mathbf x$Jacobian $= A$
    $L = \mathbf x^\top A\mathbf x$$dL = d\mathbf x^\top A\mathbf x + \mathbf x^\top A\,d\mathbf x = \mathbf x^\top(A^\top + A)\,d\mathbf x$$\nabla L = (A + A^\top)\mathbf x$ ($=2A\mathbf x$ if symmetric)
    $L = \|A\mathbf x - \mathbf b\|^2$$\mathbf r = A\mathbf x - \mathbf b$; $dL = 2\mathbf r\cdot d\mathbf r = 2\mathbf r^\top A\,d\mathbf x$$\nabla L = 2A^\top(A\mathbf x - \mathbf b)$

    In the third row, $d\mathbf x^\top A\mathbf x$ is a scalar, so it equals its own transpose $\mathbf x^\top A^\top d\mathbf x$. The fourth row is the chain rule in action: the scalar $L = \|\mathbf r\|^2$ has gradient $2\mathbf r$ with respect to $\mathbf r$, and $\mathbf r$ has Jacobian $A$. Multiply: $(2\mathbf r^\top)A$ is a row vector, and transposing it gives $2A^\top\mathbf r$. Notice the pattern that will repeat all the way through backprop: the upstream gradient gets multiplied by the transpose of the local Jacobian.

    Setting the least-squares gradient to zero gives the normal equations $A^\top A\,\mathbf x = A^\top\mathbf b$: the closed-form solution of linear regression you'll implement in lesson 13. Alternatively, follow the gradient downhill:

    Try it: right, the loss $L(\mathbf w) = \|A\mathbf w - \mathbf b\|^2$ over the two parameters of a line $\hat y = w_0 + w_1x$ (row $i$ of $A$ is $(1, x_i)$). Drag $\mathbf w$; the left panel shows the line and the residuals $r_i$. The arrow is $-\nabla L = -2A^\top\mathbf r$: each data point pushes $\mathbf w$ in the direction of its row $(1, x_i)$, weighted by its residual, and the arrow is the sum of these pushes. It's always perpendicular to the contour. Press "gradient step" a few times, or "solve" to jump to the normal-equation solution, where the arrow vanishes.

    4. Gradients with respect to matrices, and the shape rule

    Network weights are matrices. Take one linear layer and a squared-error loss:

    $$\mathbf z = W\mathbf x\quad(W\text{ is } m\times n),\qquad L = \tfrac12\|\mathbf z - \mathbf y\|^2.$$

    The gradient $\partial L/\partial W$ is the $m\times n$ array of numbers $\partial L/\partial W_{ij}$. It has the same shape as $W$, because there's one partial derivative per parameter, and that's what the update $W \leftarrow W - \eta\,\partial L/\partial W$ needs. Derive it entry by entry. $W_{ij}$ only affects $z_i = \sum_j W_{ij}x_j$, with $\partial z_i/\partial W_{ij} = x_j$. And $\partial L/\partial z_i = z_i - y_i =: \delta_i$. So

    $$\frac{\partial L}{\partial W_{ij}} = \delta_i\,x_j \quad\Longrightarrow\quad \boxed{\;\frac{\partial L}{\partial W} = \boldsymbol\delta\,\mathbf x^\top\;}\quad (m\times1)(1\times n) = m\times n.$$

    An outer product: "upstream gradient times input". You saw its one-neuron version in lesson 05, problem 6. The gradient with respect to the input is $\partial L/\partial\mathbf x = W^\top\boldsymbol\delta$, the transpose rule again.

    The shape rule as a derivation shortcut. For a batch, $Z = XW$ with $X$ of shape $N\times n$ (one example per row), $W$ of shape $n\times m$, and upstream gradient $G = \partial L/\partial Z$ of shape $N\times m$. The answer for $\partial L/\partial W$ must be $n\times m$ and must be built from $X$ and $G$. The only product of those that has that shape is $X^\top G$. Likewise $\partial L/\partial X$ must be $N\times n$: that's $G\,W^\top$. Each is easy to confirm with indices, and the shapes alone point to the right answer far more often than not.

    A bias $\mathbf b$ that's broadcast over the batch ($Z = XW + \mathbf b$) gets the gradient summed over the batch: $\partial L/\partial\mathbf b = \sum_{\text{rows}} G$. That's the sum over paths from section 2: one $\mathbf b$ feeds all $N$ rows. Forgetting the sum (or using a mean when the loss already averages) is a classic backprop bug.

    5. The softmax Jacobian

    Softmax turns a vector of scores (logits) into probabilities (lesson 14, and every attention layer in lesson 22):

    $$p_i = \frac{e^{z_i}}{\sum_k e^{z_k}}.$$

    Every output depends on every input (through the denominator), so the Jacobian is full. Let $S = \sum_k e^{z_k}$, so $\partial S/\partial z_j = e^{z_j}$. Quotient rule:

    $$\frac{\partial p_i}{\partial z_j} = \frac{\delta_{ij}e^{z_i}\,S - e^{z_i}e^{z_j}}{S^2} = p_i\,\delta_{ij} - p_ip_j \qquad\Longrightarrow\qquad \boxed{\;J = \operatorname{diag}(\mathbf p) - \mathbf p\mathbf p^\top\;}$$

    ($\delta_{ij}$ is 1 if $i=j$, else 0.) Three properties are worth checking against the figure:

    • $J$ is symmetric.
    • Every row and column sums to 0. The probabilities always sum to 1, so if one goes up, others must go down by the same total.
    • $J\mathbf 1 = \mathbf 0$: adding the same constant to every logit changes nothing. That's why the "subtract the max" trick for numerical stability is free.
    Try it: move the logit sliders. Left: logits (outlined) and probabilities (filled). Right: the Jacobian $\partial p_i/\partial z_j$ (blue positive, pink negative). Raising your own logit raises your probability (positive diagonal) and lowers everyone else's (negative off-diagonal). Make one logit dominate: the whole Jacobian fades toward 0. A saturated softmax barely passes gradient, which is the same trouble as a saturated sigmoid (lesson 05), and the reason attention scores are scaled by $1/\sqrt{d}$ (lesson 22).

    In practice softmax is followed by cross-entropy, $L = -\log p_y$ for the true class $y$. Chaining the two Jacobians collapses to something beautifully simple: $\nabla_{\mathbf z}L = \mathbf p - \mathbf e_y$, "predicted minus true" (problem 8). You'll derive and use it in lesson 14, and frameworks fuse the two operations for exactly this reason.

    6. A computation graph, forward and backward

    Put it together on the smallest interesting model: two linear layers and a squared error.

    $$\mathbf h = W_1\mathbf x, \qquad \hat y = \mathbf w_2\cdot\mathbf h, \qquad L = \tfrac12(\hat y - y)^2.$$

    The forward pass computes and stores each intermediate value. The backward pass starts from $\partial L/\partial L = 1$ and walks the graph in reverse. At each node it multiplies the incoming gradient by the transpose of that node's local Jacobian, and each parameter's gradient comes out in its own shape. We write $\bar v$ for $\partial L/\partial v$ (the "adjoint" of $v$):

    $$\bar{\hat y} = \hat y - y,\qquad \bar{\mathbf w}_2 = \bar{\hat y}\,\mathbf h,\qquad \bar{\mathbf h} = \bar{\hat y}\,\mathbf w_2,\qquad \bar W_1 = \bar{\mathbf h}\,\mathbf x^\top,\qquad \bar{\mathbf x} = W_1^\top\bar{\mathbf h}.$$
    Try it: press "next" to step through the forward pass (values in the boxes) and then the backward pass (gradients below the boxes). Each step's arithmetic is shown in the readout. Change the target $y$ and step through again: when $\hat y = y$ every gradient is zero. Check the shape rule on every parameter: $\bar W_1$ is 2×2 like $W_1$, and $\bar{\mathbf w}_2$ has 2 entries like $\mathbf w_2$.
    Worked example: the numbers in the figure (target $y = 1$)

    $\mathbf x = (1, 2)$, $W_1 = \begin{bmatrix}0.5 & -1\\ 1.5 & 0.5\end{bmatrix}$, $\mathbf w_2 = (1, 0.5)$.

    Forward. $\mathbf h = W_1\mathbf x = (0.5 - 2,\; 1.5 + 1) = (-1.5, 2.5)$. $\hat y = 1(-1.5) + 0.5(2.5) = -0.25$. $L = \tfrac12(-1.25)^2 = 0.78125$.

    Backward. $\bar{\hat y} = -0.25 - 1 = -1.25$. Then $\bar{\mathbf w}_2 = -1.25\,(-1.5, 2.5) = (1.875, -3.125)$ and $\bar{\mathbf h} = -1.25\,(1, 0.5) = (-1.25, -0.625)$.

    $\bar W_1 = \bar{\mathbf h}\,\mathbf x^\top = \begin{bmatrix}-1.25 & -2.5\\ -0.625 & -1.25\end{bmatrix}$, and $\bar{\mathbf x} = W_1^\top\bar{\mathbf h} = (0.5(-1.25) + 1.5(-0.625),\; -1(-1.25) + 0.5(-0.625)) = (-1.5625, 0.9375)$.

    Sanity check by intuition: $\hat y = -0.25$ is below the target $1$, so descent should raise $\hat y$. The first entry of $\bar{\mathbf w}_2$ is $+1.875$, so gradient descent decreases $w_{2,1}$. Since $h_1 = -1.5$ is negative, decreasing $w_{2,1}$ does raise $\hat y = w_{2,1}h_1 + w_{2,2}h_2$. ✓ The more reliable check is numerical: nudge $(W_1)_{11}$ up by $10^{-6}$ and $L$ changes by $-1.25\times10^{-6}$, matching $(\bar W_1)_{11} = -1.25$. The workbook automates this "gradient check".

    7. Why reverse mode: vector–Jacobian products

    For a pipeline $\mathbf x\to\mathbf u_1\to\cdots\to L$, the chain rule says the full derivative is a product $J_L\,J_{L-1}\cdots J_1$, where $J_L$ is a single row because the loss is a scalar. Matrix multiplication is associative, so we can evaluate the product in any order, but the cost differs enormously:

    • Forward mode (right to left): $J_2J_1$ first, then $J_3(J_2J_1)$, and so on. Every intermediate is a full Jacobian with one column per input: matrix × matrix at every step. Equivalently, push one input direction forward at a time (a Jacobian–vector product), once per input.
    • Reverse mode (left to right): $J_L J_{L-1}$ is a row vector times a matrix, and the result is again a row vector. Every step is a vector × matrix product (a vector–Jacobian product, VJP). That's exactly the "upstream gradient times local Jacobian" of section 6.

    With $n$ parameters and $m$ outputs, forward mode costs about $n$ passes and reverse mode about $m$ passes. A network has $n$ in the millions or billions and $m = 1$. Reverse mode gets every parameter's gradient for roughly the cost of one extra forward pass. The catch is memory: the backward pass needs the intermediate values from the forward pass, so they must all be stored.

    Try it: a chain of Jacobians for a network with $n$ inputs, hidden width $d$, and $m$ outputs, drawn to (log) scale at the top. The bars compare the multiply–adds needed to get the full derivative by forward mode versus reverse mode. Set $m = 1$ (a scalar loss) and raise $n$: reverse mode wins by a factor of $n$. Now flip it, with one input and many outputs, and forward mode wins. Frameworks offer both (jvp and vjp in JAX and PyTorch), but training always uses reverse.

    This is backpropagation, discovered several times and popularised for neural networks in 1986. In lesson 17 you'll build "micrograd", a tiny autograd engine. Every operation records its inputs on the forward pass and knows its own VJP. Calling loss.backward() walks the recorded graph in reverse, summing gradients where paths merge. Everything you need for it is in this lesson.

    8. Problems

    Problem 1
    warm-up

    Compute the Jacobian of $\mathbf f(x,y) = (x^2y,\; x + 3y)$ at $(1, 2)$. Enter its entries row by row.

    Solution

    Row 1 is the gradient of $x^2y$: $(2xy, x^2) = (4, 1)$. Row 2 is the gradient of $x + 3y$: $(1, 3)$. So $J = \begin{bmatrix}4&1\\1&3\end{bmatrix}$.

    Problem 2
    warm-up

    Let $A = \begin{bmatrix}1&2\\3&4\\5&6\end{bmatrix}$ and $L(\mathbf x) = \mathbf 1^\top A\mathbf x$ (the sum of the entries of $A\mathbf x$). Find $\nabla_{\mathbf x}L$. What shape must it have?

    Solution

    $L = (A^\top\mathbf 1)\cdot\mathbf x$, so $\nabla L = A^\top\mathbf 1$, the column sums: $(1+3+5, 2+4+6) = (9, 12)$. It has 2 entries, like $\mathbf x$. Using the transpose rule: the upstream gradient for $A\mathbf x$ is $\mathbf 1$ (3 entries), and the local Jacobian is $A$, so the gradient is $A^\top\mathbf 1$.

    Problem 3
    core

    Fit a line $\hat y = w_0 + w_1x$ to the points $(0,1), (1,2), (2,2)$ by least squares, $L(\mathbf w) = \|A\mathbf w - \mathbf b\|^2$. (a) Compute $\nabla L$ at $\mathbf w = (0,0)$. (b) Solve the normal equations for the optimal $\mathbf w$. Enter the answer to (a).

    Hint

    $A = \begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix}$, $\mathbf b = (1,2,2)$. Compute $A^\top\mathbf b$ and $A^\top A$.

    Solution

    (a) At $\mathbf w = 0$ the residual is $-\mathbf b$, so $\nabla L = -2A^\top\mathbf b = -2(5, 6) = (-10, -12)$. Both components are negative, so gradient descent increases both intercept and slope. Sensible, since the data lies above the zero line.

    (b) $A^\top A = \begin{bmatrix}3&3\\3&5\end{bmatrix}$, $A^\top\mathbf b = (5,6)$. Solving: $\mathbf w = \tfrac16\begin{bmatrix}5&-3\\-3&3\end{bmatrix}(5,6) = (7/6, 1/2)$. Check: the residuals $(1 - 7/6,\ 2 - 5/3,\ 2 - 13/6) = (-1/6, 1/3, -1/6)$ sum to 0 and are orthogonal to $(0,1,2)$. That's $A^\top\mathbf r = \mathbf 0$, which is exactly what $\nabla L = 0$ means.

    Problem 4
    core

    Compute the softmax Jacobian at $\mathbf z = (0, 0, 0)$. Enter a diagonal entry and an off-diagonal entry.

    Solution

    $\mathbf p = (\tfrac13,\tfrac13,\tfrac13)$. Diagonal: $p_i - p_i^2 = \tfrac13 - \tfrac19 = \tfrac29$. Off-diagonal: $-p_ip_j = -\tfrac19$. Each row: $\tfrac29 - \tfrac19 - \tfrac19 = 0$ ✓.

    Problem 5
    core · derivation

    Derive $\nabla_{\mathbf x}(\mathbf x^\top A\mathbf x) = (A + A^\top)\mathbf x$ in index notation (no differentials), and explain why only the symmetric part of $A$ matters for the value of $\mathbf x^\top A\mathbf x$.

    Solution

    $\mathbf x^\top A\mathbf x = \sum_{i,j}x_iA_{ij}x_j$. Differentiating by $x_k$ with the product rule, the terms with $i = k$ give $\sum_jA_{kj}x_j = (A\mathbf x)_k$ and those with $j = k$ give $\sum_ix_iA_{ik} = (A^\top\mathbf x)_k$. Sum: $((A + A^\top)\mathbf x)_k$. Write $A = S + K$ with $S = \tfrac12(A + A^\top)$ symmetric and $K = \tfrac12(A - A^\top)$ antisymmetric. Then $\mathbf x^\top K\mathbf x$ is a scalar equal to its own transpose $\mathbf x^\top K^\top\mathbf x = -\mathbf x^\top K\mathbf x$, so it's zero. The gradient $(A + A^\top)\mathbf x = 2S\mathbf x$ agrees.

    Problem 6
    core

    Run the computation graph of section 6 with $\mathbf x = (2, -1)$, $W_1 = \begin{bmatrix}1&0\\1&1\end{bmatrix}$, $\mathbf w_2 = (2, -1)$, target $y = 0$. Find $L$ and $\bar W_1 = \partial L/\partial W_1$. Enter $\bar W_1$ row by row.

    Solution

    Forward: $\mathbf h = (2, 2 - 1) = (2, 1)$, $\hat y = 4 - 1 = 3$, $L = 4.5$. Backward: $\bar{\hat y} = 3$, $\bar{\mathbf h} = 3\mathbf w_2 = (6, -3)$, $\bar W_1 = \bar{\mathbf h}\mathbf x^\top = \begin{bmatrix}12 & -6\\ -6 & 3\end{bmatrix}$. (Also $\bar{\mathbf w}_2 = 3\mathbf h = (6, 3)$.) Note that $\bar W_1$ has rank 1: for a single example, every weight gradient of a linear layer is an outer product.

    Problem 7
    core · conceptual

    A model has $10^8$ parameters and a scalar loss. One forward pass costs $F$ FLOPs. Roughly how much does it cost to get the full gradient (a) with finite differences, (b) with forward-mode differentiation, (c) with reverse mode? Why is (a) still useful?

    Solution

    (a) Central differences need 2 forward passes per parameter: $2\times10^8F$. (b) Forward mode needs one JVP per input direction, each a small constant times $F$: about $10^8F$. (c) Reverse mode needs one forward and one backward pass, about $2$–$3F$ in total, independent of the parameter count. Finite differences are still the gold-standard test: check a handful of random entries of your hand-written or autograd gradient, in float64 (lesson 05, section 7).

    Problem 8
    stretch

    Let $L = -\log p_y$ with $\mathbf p = \operatorname{softmax}(\mathbf z)$. Using the chain rule with the softmax Jacobian, show $\nabla_{\mathbf z}L = \mathbf p - \mathbf e_y$. Evaluate it for $\mathbf z = (1, 2, 0.5)$ and $y = 0$ (first class).

    Hint

    $\partial L/\partial\mathbf p$ is zero except entry $y$, which is $-1/p_y$. Multiply that row vector by $J$: only row $y$ of $J$ survives.

    Solution

    $\bar{\mathbf p} = -\mathbf e_y/p_y$. Then $\bar{\mathbf z} = J^\top\bar{\mathbf p} = J\bar{\mathbf p}$ (J is symmetric) $= -\tfrac{1}{p_y}\times(\text{column } y \text{ of } J)$. Column $y$ of $\operatorname{diag}(\mathbf p) - \mathbf p\mathbf p^\top$ is $p_y\mathbf e_y - p_y\mathbf p$. Dividing by $-p_y$: $\bar{\mathbf z} = \mathbf p - \mathbf e_y$. For $\mathbf z = (1, 2, 0.5)$: $\mathbf p \approx (0.2312, 0.6285, 0.1402)$, so $\bar{\mathbf z}\approx(-0.7688, 0.6285, 0.1402)$. The gradient pushes the true class's logit up and the others down, in proportion to how wrong the prediction is.

    Problem 9
    stretch

    For the batched layer $Z = XW$ ($X$: $N\times n$, $W$: $n\times m$) with upstream gradient $G = \partial L/\partial Z$, prove $\partial L/\partial W = X^\top G$ and $\partial L/\partial X = GW^\top$ in index notation.

    Solution

    $Z_{ab} = \sum_kX_{ak}W_{kb}$. By the chain rule (sum over all paths, i.e. all entries of $Z$): $\dfrac{\partial L}{\partial W_{ij}} = \sum_{a,b}G_{ab}\dfrac{\partial Z_{ab}}{\partial W_{ij}} = \sum_{a,b}G_{ab}X_{ai}\delta_{bj} = \sum_aX_{ai}G_{aj} = (X^\top G)_{ij}$. Similarly $\dfrac{\partial L}{\partial X_{ij}} = \sum_{a,b}G_{ab}\delta_{ai}W_{jb} = \sum_bG_{ib}W_{jb} = (GW^\top)_{ij}$. The sum over $a$ in the first formula is a sum over the batch: every example contributes its own outer product $\mathbf x_a\mathbf g_a^\top$.

    9. Quick check

    A layer has weight matrix $W$ of shape 128×64. What is the shape of $\partial L/\partial W$ for a scalar loss $L$?
    One partial derivative per parameter, arranged like the parameter, so you can write $W \leftarrow W - \eta\,\partial L/\partial W$. (Option c has the right number of entries but the wrong arrangement. The batch size gets summed out.)
    What does the Jacobian of $\tanh$ applied elementwise to a vector of length $n$ look like?
    Output $i$ depends only on input $i$, so all off-diagonal partials are zero. That's why elementwise ops are applied in backprop with an elementwise multiply instead of a matrix product.
    $\mathbf u = \mathbf f(\mathbf x)$ with $\mathbf x\in\mathbb R^3$, $\mathbf u\in\mathbb R^5$, and $\mathbf y = \mathbf g(\mathbf u)\in\mathbb R^2$. Which expression is the Jacobian of $\mathbf y$ with respect to $\mathbf x$?
    Outer Jacobian (2×5) at the inner value $\mathbf u$, times inner Jacobian (5×3). Option (c) has the right shape but evaluates $J_{\mathbf g}$ at the wrong point: the vector version of lesson 05's classic slip. (d) is the transpose of the answer, which is what you multiply upstream gradients by in the backward pass, but it isn't the Jacobian itself.
    Why does every deep-learning framework compute gradients in reverse mode?
    Cost scales with the number of outputs in reverse mode and the number of inputs in forward mode. For one loss and millions of parameters, the choice is clear. Reverse mode actually uses more memory (it stores activations), and both modes are exact.
