Part 5 · Deep learning

Embeddings & sequence models

Language models predict the next symbol. This lesson builds that idea up from nothing. First a table of counts, then the same table learned by gradient descent, then a network that looks at several previous characters through learned embeddings, and finally a recurrent network that can, in principle, look back forever. That "in principle" fails for a precise mathematical reason, and the failure is exactly why attention (lesson 22) was invented.

By the end you can

  • Explain why an embedding lookup is a matrix product with a one-hot vector.
  • Build a character bigram model from counts, sample from it, and score it by negative log-likelihood.
  • Explain why gradient descent on a "neural bigram" recovers the counting solution.
  • Describe Bengio et al.'s MLP language model and what its learned embeddings capture.
  • Write the RNN recurrence, unroll it, and derive why gradients vanish or explode through time.

    1. From symbols to vectors

    A network needs numbers, but a character is a symbol. Step one is a vocabulary: list the $V$ distinct characters and give each an integer id. Shakespeare's text has $V = 65$: upper- and lowercase letters, punctuation, space, newline, and a stray digit. Step two: turn id $i$ into a vector the network can multiply.

    The neutral choice is the one-hot vector $\mathbf{e}_i \in \mathbb{R}^V$, with a 1 in position $i$ and zeros elsewhere. Every pair of one-hot vectors is orthogonal and equidistant (lesson 01). The encoding claims nothing about which characters are similar. Feed it to a linear layer $E \in \mathbb{R}^{V\times d}$ and watch what happens:

    $$\mathbf{e}_i^\top E = \text{row } i \text{ of } E.$$

    Multiplying by a one-hot vector just selects a row. So a "linear layer on one-hot inputs" is a lookup table of $V$ learned vectors, one per symbol: the symbol's embedding. Real code skips the multiply (it would be $V\cdot d$ multiplications, all but $d$ of them by zero) and indexes E[i] directly. That's nn.Embedding. The gradient is the same as for the matmul, too. Only the selected rows receive gradient, and a row used several times in a batch accumulates (lesson 17 §5).

    Try it: click a character (or a row of $E$). The one-hot row vector times the $8\times4$ embedding matrix lights up exactly one row, and the product equals that row. The embeddings here are random. Training will move them so that characters which behave alike end up close together (§5).

    2. The bigram model: just count

    The simplest language model predicts the next character from the current one alone: $P(x_{t+1} \mid x_t)$. A bigram is a pair of adjacent characters. To estimate the probabilities, count every adjacent pair in the training text into a $V\times V$ table $C$, then normalize each row:

    $$P(b \mid a) = \frac{C[a, b]}{\sum_{b'} C[a, b']}.$$

    By lesson 10, this is exactly the maximum-likelihood estimate: among all tables of conditional probabilities, it's the one that makes the training text most probable. To generate text, start with a character, sample the next from row $P(\cdot\mid a)$, and repeat.

    Try it: left, the bigram counts from the opening of Coriolanus, built live in your browser and log-scaled so rare pairs stay visible (rows: current character, columns: next; letters lowercased, all punctuation shown as ".", newline and space as "␣"). Click a row to see its normalized distribution on the right. Look at the row for "q", which always leads to "u", and the column for "␣", which follows letters that end words. Press sample to generate text from these probabilities. It has the right letter statistics and no words.

    3. Scoring a model: negative log-likelihood

    How good is a language model? Ask how probable it finds real text it hasn't seen. The probability of a whole sequence is a product of tiny numbers, so take logs and average over positions (lessons 10–11):

    $$\mathrm{NLL} = -\frac{1}{T}\sum_{t=1}^{T}\log P(x_{t+1}\mid x_t).$$

    Lower is better. This is the cross-entropy between the text and the model, measured in nats per character. Two reference points. A model that guesses uniformly scores $\log V = \log 65 \approx 4.17$. A perfect model that knew every next character would score 0. The bigram model gets about 2.45 on Shakespeare. Perplexity $e^{\mathrm{NLL}}$ translates this into an "effective number of choices": $e^{2.45}\approx 11.6$ equally likely next characters, down from 65.

    Worked example: counts, NLL and the zero problem

    Train on the text the cat sat on the mat. The character t appears 4 times before another character. It's followed by h twice and by a space twice (the final t has no successor). So $P(\text{h}\mid\text{t}) = 2/4 = 0.5$. And h is always followed by e: $P(\text{e}\mid\text{h}) = 2/2 = 1$.

    NLL of the string the (two predictions): $-\tfrac12(\log 0.5 + \log 1) = 0.347$ nats.

    Now score tat. $P(\text{a}\mid\text{t}) = 0/4 = 0$, so $-\log 0 = \infty$. One unseen pair makes the loss infinite. The fix is smoothing: add a pseudo-count $\alpha$ to every cell before normalizing. With $\alpha = 1$ and the corpus's 10 distinct characters, $P(\text{a}\mid\text{t}) = (0+1)/(4+10) = 0.071$ and $P(\text{h}\mid\text{t}) = 3/14 = 0.214$. That is a Bayesian prior (lesson 10) in disguise.

    4. The same model, learned by gradient descent

    Now forget counting. Give the model a $V\times V$ matrix of parameters $W$ and define

    $$\text{logits} = \mathbf{e}_{x_t}^\top W = W[x_t], \qquad P(\cdot\mid x_t) = \mathrm{softmax}(W[x_t]),$$

    and minimize the average cross-entropy over all adjacent pairs with gradient descent. This is a one-layer neural network on one-hot inputs. What does it converge to? Take the gradient with respect to row $a$ (lesson 14's softmax gradient, summed over the $n_a$ positions where the current character is $a$):

    $$\frac{\partial\,\mathrm{NLL}}{\partial W[a]} = \frac{1}{T}\sum_{t:\,x_t = a}\big(\mathrm{softmax}(W[a]) - \mathbf{e}_{x_{t+1}}\big) = \frac{n_a}{T}\Big(\mathrm{softmax}(W[a]) - \frac{C[a,\cdot]}{n_a}\Big).$$

    It's zero exactly when $\mathrm{softmax}(W[a]) = C[a,\cdot]/n_a$: the counting solution, with $W[a] = \log C[a,\cdot] + \text{const}$. Gradient descent on the neural bigram rediscovers the count table. The point isn't to replace counting. The point is that the neural version is a framework you can extend: more context, shared structure, embeddings. Counting can't do any of that, because a table indexed by 10 previous characters would have $65^{10}$ rows.

    Try it: press train. Left, the learned $\mathrm{softmax}(W)$, starting from $W = 0$ (every row uniform). Right, the training NLL falling toward the dashed line, the count model's NLL on the same text. It never goes below the dashed line: the counts are the optimum. Rare rows, the ones with small $n_a$, converge last, because their gradient is scaled by $n_a/T$. Adam's per-parameter scaling (lesson 18) fixes exactly that.

    5. More context: the MLP language model

    Bengio, Ducharme, Vincent and Jauvin (2003) proposed the model that started neural language modeling. To predict $x_{t+1}$ from the previous $k$ characters:

    1. Embed each of the $k$ context characters with a shared table $E\in\mathbb{R}^{V\times d}$, giving $k$ vectors of size $d$.
    2. Concatenate them into one vector of size $kd$.
    3. A hidden layer: $\mathbf{h} = \tanh(W_1[\ldots] + \mathbf{b}_1)$.
    4. Logits $= W_2\mathbf{h} + \mathbf{b}_2$, then softmax and cross-entropy against the true next character.

    The parameter count grows only linearly with the context: $Vd + (kd\cdot H + H) + (H\cdot V + V)$. With $V = 65$, $k = 5$, $d = 10$, $H = 100$ that's 12,315 parameters, versus the $65^5\approx10^9$ cells a count table would need. Better still, the embedding table is shared across positions and across contexts. What the model learns about "e" in one context transfers to every other context containing "e". Characters that behave alike get pushed to nearby embeddings, because nearby embeddings produce similar predictions. Nobody tells the model which letters are vowels. It discovers that grouping because it helps predict.

    Try it: press train. An MLP language model with context $k = 3$, 2-dimensional embeddings (so we can plot them), 48 tanh hidden units and Adam trains on the same excerpt, live. Left, each character's embedding: vowels in pink, consonants in blue, space and punctuation in green. Watch them self-organize. Right, the training loss crosses below the bigram model's (dashed): three characters of context beat one. With only 2 dimensions the map is crowded. Real models use hundreds, and lesson 21's tokens get their own embeddings exactly like this.

    Every token entering GPT goes through exactly this first step: nn.Embedding(vocab_size, d_model), a learned lookup table. The geometry you met in lesson 01, with cosine similarity between embedding vectors, is the geometry of these learned tables. Word2vec's famous "king − man + woman ≈ queen" is a property of embeddings trained to predict context.

    6. Recurrent networks: a state that carries the past

    The MLP sees a fixed window of $k$ characters. To use arbitrarily long history, keep a running hidden state $\mathbf{h}_t\in\mathbb{R}^H$ and update it once per character with the same weights:

    $$\mathbf{h}_t = \tanh\big(\mathbf{x}_t W_{xh} + \mathbf{h}_{t-1}W_{hh} + \mathbf{b}\big), \qquad \text{logits}_t = \mathbf{h}_t W_{hy} + \mathbf{b}_y.$$

    Here $\mathbf{x}_t$ is the embedding of character $t$. The hidden state is a compressed summary of everything read so far. To train, unroll the loop over a sequence of length $T$. You get a $T$-layer-deep network in which every layer shares the same weights. Run ordinary backprop through it ("backpropagation through time"). Because the weights are reused at every step, their gradient is the sum of contributions from every time step: the reuse rule of lesson 17 once again.

    7. Why RNNs forget: gradients through time

    How much does the loss at step $T$ care about the state at an earlier step $t$? By the chain rule (lesson 07), with $\mathbf{z}_k$ the pre-activation at step $k$:

    $$\frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_t} = \prod_{k=t+1}^{T} \frac{\partial \mathbf{h}_k}{\partial \mathbf{h}_{k-1}} = \prod_{k=t+1}^{T} \mathrm{diag}\big(1 - \tanh^2(\mathbf{z}_k)\big)\,W_{hh}^\top .$$

    This is lesson 18's product of Jacobians with one twist that makes it worse: it's the same matrix $W_{hh}$, multiplied $T - t$ times. Suppose $W_{hh}$ has largest singular value $\rho$ (lesson 04) and the tanh derivatives are at most 1. Then $\|\partial\mathbf{h}_T/\partial\mathbf{h}_t\| \le \rho^{\,T-t}$. If $\rho \lt 1$, the gradient from 50 steps back is crushed by a factor of $\rho^{50}$ ($0.9^{50}\approx 0.005$). If $\rho$ is large, the linear part blows up instead. Either way, the signal that should teach the network "this character matters 50 steps later" doesn't arrive intact. In practice vanilla RNNs remember about 10–20 steps.

    Worked example: a one-unit RNN by hand

    Take $H = 1$: $h_t = \tanh(w\,h_{t-1} + x_t)$ with $w = 0.5$, $h_0 = 0$, and inputs $x = (1, 0, 0)$. Only the first input carries information.

    Forward: $h_1 = \tanh(1) = 0.762$, $h_2 = \tanh(0.5\cdot0.762) = 0.363$, $h_3 = \tanh(0.5\cdot0.363) = 0.180$. The memory of $x_1$ fades a little more at every step.

    Backward: each step's local derivative is $\partial h_t/\partial h_{t-1} = (1 - h_t^2)\,w$, giving $(1 - 0.363^2)(0.5) = 0.434$ for step 2 and $(1 - 0.180^2)(0.5) = 0.484$ for step 3. So $\partial h_3/\partial h_1 = 0.484\cdot0.434 = 0.210$. Each step multiplies by at most $|w| = 0.5$, so 20 steps back the factor is at most $0.5^{20}\approx 10^{-6}$. The loss at step 21 can barely tell $w$ or $x_1$ that they mattered.

    Try it: a 32-unit RNN is unrolled for 40 steps in your browser, and we backpropagate from the last state. Top: each time step's box is shaded by $\|\partial L/\partial\mathbf{h}_t\|$. Bottom: $\log_{10}$ of that norm against the distance back in time. Slide the recurrent weight scale. Below about 1 the curve falls in a straight line, which on a log scale means exponential decay. With the linear activation and a large scale, it shoots up instead (exploding gradients). With tanh, saturation tames the explosion but still loses information.

    The classic fixes treat the symptoms. Gradient clipping rescales the gradient when its norm exceeds a threshold, which stops explosions. LSTMs and GRUs add a gated, mostly additive memory cell, $\mathbf{c}_t = \mathbf{f}_t\odot\mathbf{c}_{t-1} + \dots$. That's a residual connection through time (lesson 18 §9), and it lets gradients survive hundreds of steps. But the deeper problem remains. Information from position $t$ must squeeze through every intermediate state to reach position $T$, and it's processed strictly one step at a time, which is slow on parallel hardware.

    The motivation for attention (lesson 22). What if position $T$ could look directly at every earlier position and decide, from their contents, which ones matter? Then the path between any two positions is one step long: no product of $T - t$ Jacobians, no vanishing. All positions can also be computed in parallel. That's self-attention: a dot product between a query and every key (lesson 01's similarity), a softmax over positions (lesson 14), and a weighted sum. The transformer (lesson 23) is that mechanism plus the MLP, embeddings, LayerNorm and residual connections from this part of the course.

    8. Problems

    Problem 1
    warm-up

    What NLL (in nats per character) does a model that predicts uniformly over Shakespeare's $V = 65$ characters achieve? What's its perplexity?

    Solution

    Every prediction has probability $1/65$: $\mathrm{NLL} = \log 65 \approx 4.174$, and perplexity $= 65$. Perplexity of a uniform model is its vocabulary size.

    Problem 2
    warm-up

    The bigram model scores NLL $= 2.45$ nats. What is its perplexity?

    Solution

    $e^{2.45}\approx 11.59$. The model is "as uncertain as" a uniform choice among about 12 characters.

    Problem 3
    core

    Count the parameters of an MLP language model with $V = 65$, context $k = 8$, embedding size $d = 16$ and $H = 200$ hidden units (biases included).

    Solution

    Embedding $65\cdot16 = 1{,}040$. Hidden: $(8\cdot16)\cdot200 + 200 = 25{,}800$. Output: $200\cdot65 + 65 = 13{,}065$. Total $39{,}905$.

    Problem 4
    core

    Using add-one smoothing on the corpus the cat sat on the mat (10 distinct characters), compute $P(\text{h}\mid\text{t})$ and the NLL of the string tha (two predictions). Enter the NLL.

    Hint

    Row h: h is followed by e twice, so the smoothed row is $(2+1)/(2+10)$ for e and $1/12$ for everything else.

    Solution

    $P(\text{h}\mid\text{t}) = 3/14 \approx 0.214$ and $P(\text{a}\mid\text{h}) = 1/12$. $\mathrm{NLL} = -\tfrac12(\log\tfrac{3}{14} + \log\tfrac1{12}) = \tfrac12(1.540 + 2.485) = 2.013$.

    Problem 5
    core · derivation

    Show that the minimizer of the neural-bigram loss satisfies $\mathrm{softmax}(W[a]) = C[a,\cdot]/n_a$ for every row $a$ with $n_a > 0$. Why is $W$ not unique? What happens to $W[a][b]$ when $C[a,b] = 0$?

    Solution

    The loss separates into rows: $\mathrm{NLL} = \frac1T\sum_a\big(-\sum_b C[a,b]\log\mathrm{softmax}(W[a])_b\big)$. Each row's term is $n_a$ times the cross-entropy between $\hat p_a = C[a,\cdot]/n_a$ and $q = \mathrm{softmax}(W[a])$. That cross-entropy equals $H(\hat p_a) + \mathrm{KL}(\hat p_a\|q)$ (lesson 11), which is minimized exactly when $\mathrm{KL} = 0$, i.e. $q = \hat p_a$. Softmax is invariant to adding a constant to all logits in a row, so $W[a] + c\mathbf{1}$ is equally good. If $C[a,b] = 0$, the optimum wants $q_b = 0$, which needs $W[a][b]\to-\infty$. Gradient descent keeps pushing it down forever. Weight decay, or count smoothing, keeps it finite.

    Problem 6
    core

    Suppose each backward step through an RNN multiplies the gradient norm by 0.9. After how many time steps has the gradient shrunk to 1% of its size?

    Solution

    $0.9^k = 0.01 \Rightarrow k = \ln 0.01/\ln 0.9 \approx 43.7$ steps. A per-step factor that looks harmless destroys the signal within a sentence or two.

    Problem 7
    core

    An RNN language model takes one-hot characters directly ($V = 65$), has $H = 128$ hidden units and an output layer to 65 logits. How many parameters, with biases on the hidden update and the output?

    Solution

    $W_{xh}$: $65\cdot128 = 8{,}320$. $W_{hh}$: $128^2 = 16{,}384$. $\mathbf{b}$: 128. $W_{hy}$: $128\cdot65 = 8{,}320$. $\mathbf{b}_y$: 65. Total $33{,}217$. Note that this count is independent of the sequence length: the same weights are reused at every step.

    Problem 8
    stretch

    For a linear RNN $\mathbf{h}_t = \mathbf{h}_{t-1}W$ with $W$ diagonalizable as $W = Q\Lambda Q^{-1}$, write $\partial\mathbf{h}_T/\partial\mathbf{h}_0$ in terms of the eigenvalues. Why does clipping the gradient norm fix exploding gradients but not vanishing ones?

    Solution

    $\mathbf{h}_T = \mathbf{h}_0W^T$, so the Jacobian is $(W^T)^\top$, and $W^T = Q\Lambda^TQ^{-1}$ (lesson 04). Each eigen-direction is scaled by $\lambda_i^T$. Directions with $|\lambda_i| \lt 1$ vanish, and those with $|\lambda_i| > 1$ explode, exponentially in $T$. Clipping shrinks a too-large gradient back to a sane length while keeping its direction, so a training step stays reasonable. But a vanished gradient has lost the information about long-range dependencies: it's $10^{-20}$ of the true signal, buried under the short-range terms. Scaling it up can't restore it. That needs an architectural change: gated or additive memory (LSTM), or direct connections (attention).

    9. Quick check

    Why does nn.Embedding index a table instead of multiplying a one-hot vector by a matrix?
    $\mathbf{e}_i^\top E$ is row $i$. Same value, same gradient (only row $i$ gets one), far less work.
    A neural bigram (W of shape V×V, softmax, cross-entropy) is trained to convergence. Compared with the count-based bigram on the training text, its NLL is…
    Same model class, same objective. The counts are the global optimum (problem 5), and the convex per-row loss lets gradient descent approach them.
    Why do vanilla RNNs struggle with dependencies 100 steps apart?
    Long-range learning signal vanishes (or explodes) geometrically. Attention removes the long product by connecting positions directly.
