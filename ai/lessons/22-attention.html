Part 6 · Transformers

Attention

Attention is how a transformer lets each token gather information from the others, with weights computed from the content itself. Mechanically it is a dot product, a softmax and a weighted average: three things you already know. This lesson assembles them and explains each design choice, including the $\sqrt{d}$ that everyone copies and few people derive.

By the end you can

  • Explain attention as a soft, differentiable dictionary lookup with queries, keys and values.
  • Write scaled dot-product attention in matrix form, and derive why scores are divided by $\sqrt{d_k}$.
  • Apply a causal mask, and explain why it goes before the softmax.
  • Implement multi-head attention with a single reshape, and count its parameters and cost.
  • State and prove that attention is permutation-equivariant, which is why transformers need positional information (lesson 23).

    1. The problem attention solves

    In lesson 20 you built language models that predict the next character. The bigram model looked only at the previous token. The MLP model concatenated a fixed window of embeddings. The RNN squeezed the entire past into one hidden vector, updated step by step. Each one has a structural weakness:

    • A fixed window can't see beyond its edge, and it gives every position its own weights, so "cat" at position 3 and "cat" at position 5 are processed by different parameters.
    • An RNN must decide at write time what to keep in its fixed-size state, long before it knows what will be needed. It also processes tokens one after another, which is slow on parallel hardware.

    What we'd like: when the model processes "it" in "the cat sat on the mat because it was tired", it should be able to look back at every earlier token and pull in information from whichever ones are relevant (here "cat"). And the decision about what's relevant should depend on content, not on fixed positions. That operation is attention.

    2. A soft dictionary lookup

    Start with an ordinary Python dictionary. A lookup d[q] compares the query q with every key, finds the one that matches exactly, and returns its value. Two problems for a neural network: an exact match on real-valued vectors almost never happens, and "pick the one that matches" has zero gradient almost everywhere, so you can't train it.

    Attention softens each step:

    1. Compare the query $\mathbf{q}$ with every key $\mathbf{k}_j$ using a dot product (lesson 01): the score $s_j = \mathbf{q}\cdot\mathbf{k}_j$ is large when they point the same way.
    2. Normalize the scores into weights with a softmax (lesson 14): $w_j = e^{s_j} / \sum_m e^{s_m}$. The weights are positive and sum to 1.
    3. Return the weighted average of the values: $\mathbf{o} = \sum_j w_j \mathbf{v}_j$.

    If one key matches much better than the rest, the softmax puts almost all the weight on it and we recover the hard lookup. Otherwise we get a blend. Every step is differentiable, so gradients flow into the queries, keys and values.

    Try it: left, five tokens' keys (drag them) and the query (drag the orange handle). The ring around each key grows with its attention weight. Right: each token's value, with the output $\mathbf{o}=\sum_j w_j \mathbf{v}_j$ as the orange dot. The output always lies inside the shaded hull of the values, because it is a weighted average. Point the query at "cat", then make it longer in the same direction: the weights sharpen, because a longer query scales every score. The temperature slider divides all scores by $T$ (section 5).
    Worked example

    Query $\mathbf{q} = (1, 0)$. Keys $\mathbf{k}_1 = (1,0)$, $\mathbf{k}_2 = (0,1)$, $\mathbf{k}_3 = (1,1)$. Values $\mathbf{v}_1 = (1,2)$, $\mathbf{v}_2 = (3,4)$, $\mathbf{v}_3 = (5,6)$. Use the scaled scores of section 4 with $d_k = 2$:

    Scores: $\mathbf{q}\cdot\mathbf{k}_j / \sqrt2 = (1, 0, 1)/\sqrt2 = (0.7071, 0, 0.7071)$.

    Exponentials: $(e^{0.7071}, e^{0}, e^{0.7071}) = (2.0281, 1, 2.0281)$, sum $5.0562$. Weights: $(0.4011, 0.1978, 0.4011)$.

    Output: $0.4011\,(1,2) + 0.1978\,(3,4) + 0.4011\,(5,6) = (3.000, 4.000)$. Keys 1 and 3 tie, and the average of $\mathbf{v}_1$ and $\mathbf{v}_3$ happens to be $\mathbf{v}_2$, so the output lands exactly on $(3,4)$. The workbook's tests use this example.

    3. Queries, keys and values

    In self-attention the queries, keys and values all come from the same sequence. Stack the $n$ token vectors (embeddings, $d$ numbers each) as the rows of $X \in \mathbb{R}^{n \times d}$. Three learned matrices give each token three different "roles":

    $$Q = X W_Q,\qquad K = X W_K,\qquad V = X W_V, \qquad W_Q, W_K \in \mathbb{R}^{d\times d_k},\; W_V \in \mathbb{R}^{d\times d_v}.$$
    • The query $\mathbf{q}_i$ (row $i$ of $Q$) encodes what token $i$ is looking for.
    • The key $\mathbf{k}_j$ encodes what token $j$ offers, i.e. how it should be found.
    • The value $\mathbf{v}_j$ encodes what token $j$ hands over once found.

    Why separate keys from values? What makes a token findable ("I am a noun, singular, an animal") is often different from what you want to read from it ("its identity is cat"). Why separate queries from keys? Because the relation needn't be symmetric: "it" looks for nouns, but nouns don't look for "it".

    All $n^2$ scores are one matrix product, and all $n$ outputs are another:

    $$\boxed{\;\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)\,V\;}$$

    with the softmax applied to each row. Shapes: $QK^\top$ is $n\times n$, where entry $(i, j)$ is "how much token $i$ attends to token $j$". Multiplying by $V$ ($n \times d_v$) gives an $n\times d_v$ output: one new vector per token. This is exactly the matrix-of-dot-products picture from lesson 01, problem 6.

    Attention's mixing weights are computed from the input. A normal layer $XW$ applies the same fixed $W$ to every input. Attention applies $A(X)\,V$ with $A(X) = \operatorname{softmax}(XW_Q W_K^\top X^\top/\sqrt{d_k})$, a mixing matrix that depends on the sentence itself. That data-dependent routing is what makes transformers so flexible.

    4. Why divide by $\sqrt{d_k}$?

    Suppose, as at initialization, the components of $\mathbf{q}$ and $\mathbf{k}$ are independent with mean 0 and variance 1. What does a score $s = \mathbf{q}\cdot\mathbf{k} = \sum_{i=1}^{d_k} q_i k_i$ look like? Use the rules from lesson 09:

    • Each term has mean $\mathbb{E}[q_i k_i] = \mathbb{E}[q_i]\,\mathbb{E}[k_i] = 0$ (independence).
    • Each term has variance $\operatorname{Var}(q_i k_i) = \mathbb{E}[q_i^2 k_i^2] - 0 = \mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2] = 1\cdot 1 = 1$.
    • The $d_k$ terms are independent, so variances add: $\operatorname{Var}(s) = d_k$.
    $$\operatorname{Var}(\mathbf{q}\cdot\mathbf{k}) = d_k \quad\Longrightarrow\quad \operatorname{std}(\mathbf{q}\cdot\mathbf{k}) = \sqrt{d_k}, \qquad \operatorname{Var}\Big(\frac{\mathbf{q}\cdot\mathbf{k}}{\sqrt{d_k}}\Big) = 1.$$

    So with $d_k = 64$, raw scores have a typical spread of ±8. Why is that bad? The softmax compares differences of scores: two scores 16 apart give weights in the ratio $e^{16} \approx 9$ million to 1. The softmax saturates into a near one-hot vector. A saturated softmax has a vanishing gradient. Its Jacobian (problem 3) is

    $$\frac{\partial w_i}{\partial s_j} = w_i(\delta_{ij} - w_j), \qquad J = \operatorname{diag}(\mathbf{w}) - \mathbf{w}\mathbf{w}^\top,$$

    and if $\mathbf{w}$ is one-hot, every entry is $1\cdot(1-1) = 0$ or $0\cdot(\ldots) = 0$. The model would start training with attention patterns frozen in place by random initialization. Dividing by $\sqrt{d_k}$ keeps scores at unit variance whatever the head size, so the softmax starts in its responsive range.

    Try it: left, a histogram of 2,000 scores $\mathbf{q}\cdot\mathbf{k}$ for random Gaussian vectors in $\mathbb{R}^{d}$. Right, the softmax weights of one query over 10 keys. With "divide by √d" unticked, increase $d$: the scores spread out like $\sqrt{d}$ and the weights collapse onto a single key. The readout shows the softmax Jacobian's size, $\|J\|_F$, which is how much gradient can flow back. Now tick the box: the histogram stays at unit width whatever $d$ is. That's the point.

    The scale fixes the initial statistics. During training $W_Q$ and $W_K$ can still grow and saturate the softmax. Attention logits blowing up is a known instability in large models, and some recipes add a LayerNorm to queries and keys ("QK-norm") to prevent it.

    5. Temperature: one knob for sharpness

    Dividing scores by a constant is so useful that it has a name. A softmax at temperature $T$ is

    $$\operatorname{softmax}(\mathbf{s}/T)_j = \frac{e^{s_j/T}}{\sum_m e^{s_m/T}}.$$

    As $T \to 0$ it approaches a one-hot argmax. At $T = 1$ it is the plain softmax. As $T\to\infty$ it approaches the uniform distribution. For scores $(2, 1, 0)$: $T = 0.5$ gives $(0.867, 0.117, 0.016)$, $T = 1$ gives $(0.665, 0.245, 0.090)$, and $T = 2$ gives $(0.507, 0.307, 0.186)$. Scaled attention is softmax at temperature $\sqrt{d_k}$. You'll use the same knob to control randomness when sampling text in lesson 25, and it reappears in lesson 29 (DPO's $\beta$ acts like an inverse temperature).

    6. The causal mask

    A language model is trained to predict token $t+1$ from tokens $1..t$. In training we process the whole sequence at once and ask for a prediction at every position in parallel. If position $t$ could attend to position $t+1$, it could simply read the answer. So we forbid it: token $i$ may attend only to tokens $j \le i$.

    The clean way to forbid a weight is to set its score to $-\infty$ before the softmax, since $e^{-\infty} = 0$:

    $$\operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}} + M\Big)V, \qquad M_{ij} = \begin{cases} 0 & j \le i\\ -\infty & j > i.\end{cases}$$

    Masking after the softmax, by zeroing weights, would leave rows that no longer sum to 1. Adding $-\infty$ first lets the softmax renormalize over exactly the allowed keys. The resulting weight matrix is lower-triangular.

    Try it: each row is a query token and each column a key, and a cell shows how much the row attends to the column. Switch between the hand-built heads. They mimic patterns found in trained models: a previous-token head, a head that looks back at earlier copies of the same word (a building block of induction heads), and a content head where "it" finds the animate noun. Toggle the causal mask and watch the upper triangle vanish while every row still sums to 1. Click a row to read its weights.
    Worked example: masking renormalizes

    Three tokens, all scores 0 (so unmasked attention would be uniform, 1/3 each). With the causal mask, row 1 sees only token 1: weights $(1, 0, 0)$. Row 2 sees tokens 1–2: $(\tfrac12, \tfrac12, 0)$. Row 3 sees all three: $(\tfrac13, \tfrac13, \tfrac13)$. If the values are the scalars $1, 2, 3$, the outputs are $1$, $1.5$ and $2$: each position gets the running mean of the past. A causal attention layer with equal scores is a running average. Learned scores make it a weighted running average whose weights depend on content.

    7. Multi-head attention

    One softmax gives one weighted average per token: one "question" per token. But a token usually needs several things at once: the previous word for syntax, the subject of the sentence for agreement, an earlier mention for coreference. Multi-head attention runs $h$ attention operations in parallel, each in a smaller subspace of size $d_h = d/h$, and concatenates the results:

    $$\text{head}_i = \operatorname{Attention}(XW_Q^{(i)}, XW_K^{(i)}, XW_V^{(i)}),\qquad \operatorname{MHA}(X) = [\text{head}_1, \ldots, \text{head}_h]\,W_O.$$

    In code, nobody stores $h$ separate matrices. Use one $d\times d$ matrix for each of $W_Q, W_K, W_V$, and let head $i$ own columns $i\,d_h$ to $(i+1)\,d_h - 1$. Then multi-head attention is a reshape:

    q = (X @ Wq).reshape(B, n, h, dh).transpose(0, 2, 1, 3)   # (B, h, n, dh)
# ... same for k, v ...
w = softmax(q @ k.transpose(0, 1, 3, 2) / sqrt(dh))     # (B, h, n, n)
out = w @ v                                              # (B, h, n, dh): h is a batch axis
out = out.transpose(0, 2, 1, 3).reshape(B, n, d) @ Wo      # concatenate heads, mix
    Try it: change the number of heads $h$ for a model of width $d = 12$ and a sequence of $n = 6$ tokens. The columns of $Q = XW_Q$ are coloured by the head that owns them. The reshape + transpose regroups them into $h$ independent $(n \times d_h)$ blocks. Each block computes its own $n\times n$ attention pattern, shown at the right. The parameter count and the matrix-multiply cost stay the same whatever $h$ is. Only the number of separate attention patterns changes.

    Parameter count. $W_Q, W_K, W_V, W_O$ are each $d\times d$, so multi-head attention has $4d^2$ weights (plus $4d$ if there are biases), independent of $h$. For $d = 768$ that is 2,359,296 weights per layer.

    Interpretability research ("mechanistic interpretability") studies individual heads and has found previous-token heads, induction heads that implement "if A B appeared before and now A again, predict B", and heads that track syntax. Lesson 25 shows how generation caches each head's keys and values (the KV cache). Grouped-query attention, used in Llama 2/3, saves memory by letting several query heads share one key/value head.

    8. Two properties that shape the transformer

    Attention ignores order: permutation equivariance

    Shuffle the input tokens with a permutation matrix $P$ (each row of $PX$ is some row of $X$). Then $PQ = PXW_Q$ and so on, and

    $$\begin{aligned}\operatorname{softmax}\!\Big(\frac{PQ(PK)^\top}{\sqrt{d_k}}\Big)PV &= \operatorname{softmax}\!\Big(P\,\frac{QK^\top}{\sqrt{d_k}}\,P^\top\Big)PV \\ &= P\operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)P^\top P V = P\cdot\operatorname{Attention}(Q,K,V).\end{aligned}$$

    The middle step holds because permuting rows and columns of a matrix just permutes the entries within each row, which the row-wise softmax doesn't care about, and $P^\top P = I$. The output is the same set of vectors, shuffled the same way. Self-attention alone has no idea of word order: "dog bites man" and "man bites dog" produce the same outputs, just rearranged. (A causal mask does break the symmetry, but only crudely.) Lesson 23 fixes this by adding position information to the embeddings.

    Attention is quadratic

    The score matrix has $n^2$ entries per head. Computing it costs about $n^2 d$ multiply-adds, and applying it to $V$ costs the same again. Doubling the context length quadruples this part of the work. With $h = 12$ heads and $n = 2048$, one layer's attention weights alone are $12 \times 2048^2 \approx 50$ million numbers. Memory-efficient kernels like FlashAttention compute the result in tiles and never store the whole matrix, but the arithmetic is still quadratic.

    9. Problems

    Problem 1
    warm-up

    A query has (already scaled) scores $(2, 1, 0)$ against three keys whose values are the scalars $10, 20, 30$. Compute the attention weights and the output.

    Enter the output:

    Solution

    $e^2, e^1, e^0 = 7.389, 2.718, 1$, sum $11.107$. Weights $(0.6652, 0.2447, 0.0900)$. Output $0.6652\cdot10 + 0.2447\cdot20 + 0.0900\cdot30 = 6.652 + 4.895 + 2.701 = 14.248$.

    Problem 2
    warm-up

    Queries and keys have $d_k = 64$ independent components with mean 0 and variance 1. What is the standard deviation of a raw score $\mathbf{q}\cdot\mathbf{k}$? And of the scaled score?

    Enter both, comma-separated:

    Solution

    $\operatorname{Var}(\mathbf{q}\cdot\mathbf{k}) = 64$ (section 4), so the std is $8$. Dividing by $\sqrt{64} = 8$ gives std $1$.

    Problem 3
    core · derivation

    Let $w_i = e^{s_i}/\sum_m e^{s_m}$. (a) Show $\partial w_i/\partial s_j = w_i(\delta_{ij} - w_j)$. (b) Show that $J = \operatorname{diag}(\mathbf{w}) - \mathbf{w}\mathbf{w}^\top$ is the zero matrix when $\mathbf{w}$ is one-hot. (c) Show that every row of $J$ sums to 0, and explain why that must be so.

    Hint

    (a) Quotient rule, or differentiate $\log w_i = s_i - \log\sum_m e^{s_m}$ and multiply by $w_i$.

    Solution

    (a) $\log w_i = s_i - \log Z$ with $Z = \sum_m e^{s_m}$. Then $\partial \log w_i/\partial s_j = \delta_{ij} - e^{s_j}/Z = \delta_{ij} - w_j$. Multiply by $w_i$ (since $\partial w_i = w_i\,\partial\log w_i$).

    (b) If $w_k = 1$ and the rest are 0: for $i\ne k$, $w_i = 0$ kills the entry. For $i = k$, $w_k(\delta_{kj} - w_j)$ is $1\cdot(1 - 1) = 0$ when $j = k$ and $1\cdot(0 - 0) = 0$ otherwise.

    (c) $\sum_j w_i(\delta_{ij} - w_j) = w_i(1 - \sum_j w_j) = 0$. It must be so because adding the same constant to every score doesn't change the softmax (shift invariance), so the derivative along the direction $(1, 1, \ldots, 1)$ is zero.

    Problem 4
    core

    Causal attention with all scores equal, over a sequence of 5 tokens whose values are the scalars $1, 2, 3, 4, 5$. What are the 5 outputs?

    Solution

    Position $t$ averages values $1..t$: $1,\ 1.5,\ 2,\ 2.5,\ 3$. In general, $\frac{t+1}{2}$.

    Problem 5
    core

    A model has $d = 768$, $h = 12$ heads, no biases. (a) How many parameters does one multi-head attention layer have? (b) For context $n = 2048$, how many attention weights (all heads) does one layer produce, and how many megabytes is that in 32-bit floats?

    Enter the three numbers, comma-separated (MB = $10^6$ bytes):

    Solution

    (a) $4d^2 = 4\cdot 589{,}824 = 2{,}359{,}296$. (b) $h n^2 = 12 \cdot 4{,}194{,}304 = 50{,}331{,}648$ weights, times 4 bytes is $201.3$ MB per layer per sequence. With a batch and 12 layers it would be many gigabytes, which is why fused kernels avoid storing it.

    Problem 6
    core · proof

    Prove permutation equivariance carefully. Let $P$ be a permutation matrix and $S$ any $n\times n$ matrix. Show that $\operatorname{softmax}_{\text{rows}}(PSP^\top) = P\,\operatorname{softmax}_{\text{rows}}(S)\,P^\top$, then conclude $\operatorname{Attn}(PX) = P\operatorname{Attn}(X)$ for self-attention without a mask.

    Hint

    Write $P$ via a permutation $\pi$: $(PSP^\top)_{ij} = S_{\pi(i)\pi(j)}$.

    Solution

    $(PSP^\top)_{ij} = S_{\pi(i)\pi(j)}$. Row $i$ of the softmax is $e^{S_{\pi(i)\pi(j)}}/\sum_m e^{S_{\pi(i)\pi(m)}}$. As $m$ runs over all indices, so does $\pi(m)$, so the denominator is $\sum_{m'} e^{S_{\pi(i)m'}}$. The entry therefore equals $\operatorname{softmax}(S)_{\pi(i)\pi(j)} = (P\,\operatorname{softmax}(S)\,P^\top)_{ij}$. With $X \to PX$, $Q,K,V \to PQ, PK, PV$, the scores become $PSP^\top$, so the output is $P\,\operatorname{softmax}(S)P^\top P V = P\operatorname{softmax}(S)V$. The workbook checks this numerically.

    Problem 7
    stretch

    Show that $\mathbf{q}\cdot\mathbf{k} = \mathbf{x}_i^\top W_Q W_K^\top \mathbf{x}_j$, so a head's scores depend only on the $d\times d$ product $W_{QK} = W_Q W_K^\top$. What is the maximum rank of $W_{QK}$ for a head with $d_h = 64$ in a model with $d = 768$? Why might a low rank be fine, or even useful? (Rank: lesson 03; low-rank factorizations: lesson 04.)

    Solution

    $\mathbf{q}_i = W_Q^\top\mathbf{x}_i$ and $\mathbf{k}_j = W_K^\top \mathbf{x}_j$ (column-vector form), so $\mathbf{q}_i\cdot\mathbf{k}_j = \mathbf{x}_i^\top W_Q W_K^\top \mathbf{x}_j$. $W_Q$ is $768\times64$, so the product has rank at most 64. A head can only "ask" about a 64-dimensional subspace of the 768-dimensional token vector. That restriction is a feature: each head specializes in a few directions (one for syntax, one for position, ...), and the factorized form costs $2\cdot 768\cdot 64$ parameters instead of $768^2$. The same low-rank idea powers LoRA fine-tuning in lesson 25.

    Problem 8
    stretch · conceptual

    (a) What does the softmax do to a row in which every score is $-\infty$, and when could that happen? (b) Why does "add $-\infty$ before the softmax" beat "multiply weights by the 0/1 mask after the softmax"? (c) Many implementations use a large negative number like $-10^9$ instead of $-\infty$. When does the difference matter?

    Solution

    (a) $0/0 = $ NaN. It can't happen with a causal mask (the diagonal is always allowed), but it can with padding masks if a query has no valid keys. Implementations must special-case it. (b) Zeroing after the softmax leaves rows summing to less than 1, so the output shrinks for early positions and the model sees inconsistent scales. Adding $-\infty$ first renormalizes over the allowed keys. (c) With $-10^9$, a fully-masked row becomes uniform instead of NaN. That hides bugs but is numerically safe. In float16 the constant must fit the format (max ≈ 65504), which is why code often uses torch.finfo(dtype).min.

    10. Quick check

    In attention, what determines how much token $i$ reads from token $j$?
    Weights are computed from content: $\operatorname{softmax}_j(\mathbf{q}_i\cdot\mathbf{k}_j/\sqrt{d_k})$. Values only determine what is read, not how much. There are no per-position-pair weights, which is why attention works for any sequence length.
    You forget to divide by $\sqrt{d_k}$ in a model with $d_k = 256$. What happens at initialization?
    Softmax normalizes the sum of weights, not the spread of the scores. Large score differences saturate it, and the Jacobian $\operatorname{diag}(\mathbf{w}) - \mathbf{w}\mathbf{w}^\top$ goes to 0.
    Going from 1 head to 8 heads (same $d$), what happens to the number of attention parameters?
    Each head uses a $d\times d/h$ slice of $W_Q, W_K, W_V$ and the full $W_O$ mixes the concatenation. The total is $4d^2$ regardless. What changes is that you get $h$ independent attention patterns.
    Self-attention without any position information receives "dog bites man". What does it compute for "man bites dog"?
    Permutation equivariance: $\operatorname{Attn}(PX) = P\operatorname{Attn}(X)$. The model can't tell who bit whom, which is why lesson 23 adds positional encodings.
