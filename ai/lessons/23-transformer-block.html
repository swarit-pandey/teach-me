Part 6 · Transformers

The transformer block

Attention lets tokens talk to each other. A transformer wraps it in a small, repeated unit: normalize, attend, add back; normalize, think (MLP), add back. Stack a dozen of these on top of token and position embeddings, put a linear layer on top, and you have GPT. This lesson builds each piece, explains why it's there, and counts every parameter.

By the end you can

  • Describe a transformer as a residual stream that attention and MLP layers read from and write to, and explain why residual connections make deep stacks trainable.
  • Explain pre-norm LayerNorm placement and the role of the position-wise MLP.
  • Compare learned, sinusoidal and rotary (RoPE) position information, and prove the relative-position property of the latter two.
  • Draw the full GPT architecture with tensor shapes, and derive its parameter count: $12d^2 + 13d$ per block.

    1. One block: communicate, then compute

    A transformer block takes a sequence of $T$ vectors of width $d$, shape $(T, d)$, and returns a sequence of the same shape. It does two things, each wrapped in the same pattern:

    $$\begin{aligned} \mathbf{x} &\leftarrow \mathbf{x} + \operatorname{Attn}(\operatorname{LN}_1(\mathbf{x})) &&\text{communicate: each token reads from earlier tokens}\\ \mathbf{x} &\leftarrow \mathbf{x} + \operatorname{MLP}(\operatorname{LN}_2(\mathbf{x})) &&\text{compute: each token processes what it has, alone} \end{aligned}$$

    That's the whole block. Attention (lesson 22) is the only place where information moves between positions. The MLP is applied to each position independently, with the same weights. LayerNorm (lesson 18) keeps the inputs to each sub-layer well-scaled. The "$\mathbf{x} + \ldots$" is a residual connection (lesson 18). It turns out to be the most important design decision in the architecture, so we start there.

    2. The residual stream

    Read the block equations as an accumulator. Each token owns a vector $\mathbf{x}_t$, called its residual stream. Every sub-layer reads a (normalized) copy of the stream, computes something, and adds its result back. Nothing is ever overwritten. After $L$ blocks,

    $$\mathbf{x}^{(L)} = \mathbf{x}^{(0)} + \sum_{\ell=1}^{L}\big(\mathbf{a}^{(\ell)} + \mathbf{m}^{(\ell)}\big),$$

    the embedding plus the sum of every attention output $\mathbf{a}^{(\ell)}$ and MLP output $\mathbf{m}^{(\ell)}$. The stream is a shared workspace, a $d$-dimensional "bus" that layers use to pass information to later layers. Interpretability work reads transformers exactly this way.

    Why it makes depth trainable. For one residual layer $\mathbf{y} = \mathbf{x} + f(\mathbf{x})$, the Jacobian (lesson 07) is $\partial\mathbf{y}/\partial\mathbf{x} = I + J_f$. Backpropagating through $L$ layers multiplies these:

    $$\frac{\partial \mathbf{x}^{(L)}}{\partial \mathbf{x}^{(0)}} = \prod_{\ell=L}^{1}\big(I + J_\ell\big) = I + \sum_\ell J_\ell + \ldots$$

    Even if every $J_\ell$ is small, the identity term carries the gradient straight from the loss to the first layer. Without residuals the product is $\prod_\ell J_\ell$. If the $J$'s are a bit smaller than 1 in size it vanishes exponentially, and if a bit larger it explodes. That's the problem lesson 18 met in deep MLPs.

    Try it: each layer's Jacobian is a random $16\times16$ matrix with typical gain $g$. The plot shows $\log_{10}$ of the gradient norm after backpropagating through 1 to 60 layers. The plain stack multiplies $J_\ell$'s, the residual stack multiplies $(I + J_\ell)$'s. Move $g$: the plain stack only survives near $g = 1$ and vanishes or explodes elsewhere. The residual stack stays within a few orders of magnitude for small $g$. Real transformers initialize each branch's output layer small (GPT-2 scales it by $1/\sqrt{2L}$) to sit in that regime.

    A freshly initialized residual network with small branches is close to the identity function: input embedding in, (almost) same embedding out. Training then grows each layer's contribution from near zero. That's a much easier starting point than a deep random composition.

    3. LayerNorm, and where to put it

    LayerNorm (lesson 18) normalizes each token's vector across its $d$ features, then applies a learned scale and shift:

    $$\operatorname{LN}(\mathbf{x}) = \boldsymbol\gamma \odot \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} + \boldsymbol\beta,\qquad \mu = \frac1d\sum_i x_i,\quad \sigma^2 = \frac1d\sum_i (x_i-\mu)^2.$$

    Unlike BatchNorm, it uses statistics of a single token, so it behaves identically at training and inference time and doesn't care about batch size or sequence length. It has $2d$ parameters ($\boldsymbol\gamma$ and $\boldsymbol\beta$).

    Try it: drag the tops of the 8 input bars (one token's features). The dashed lines mark the mean and ±1 std. The output (right) always has mean $\beta$ and std $\gamma$, here per-feature parameters set to the same value for simplicity. Shift all bars up together: the output doesn't move. Scale them all: still nothing. LayerNorm only keeps the pattern of the vector, which is why its gradient along "add a constant to every feature" is zero (workbook test).
    Worked example

    $\mathbf{x} = (1, 2, 3, 6)$, $\boldsymbol\gamma = \mathbf{1}$, $\boldsymbol\beta = \mathbf{0}$, $\epsilon = 0$. Mean $\mu = 12/4 = 3$. Deviations $(-2, -1, 0, 3)$, squared $(4, 1, 0, 9)$, so $\sigma^2 = 14/4 = 3.5$ and $\sigma = 1.8708$. Output: $(-1.069, -0.535, 0, 1.604)$. Check: these sum to 0 and their squares average to 1.

    Pre-norm vs post-norm. The original 2017 transformer used post-norm: $\mathbf{x} \leftarrow \operatorname{LN}(\mathbf{x} + f(\mathbf{x}))$. That puts a LayerNorm on the residual path, so the clean identity path of section 2 is broken at every layer. Post-norm transformers need a careful learning-rate warm-up and are hard to train when deep. GPT-2 and nearly every model since use pre-norm: $\mathbf{x} \leftarrow \mathbf{x} + f(\operatorname{LN}(\mathbf{x}))$. The stream itself is never normalized, so the stream grows over depth, and one final LayerNorm before the output head ($\operatorname{LN}_f$) cleans it up. Many recent models (Llama) use RMSNorm, which skips the mean subtraction and $\boldsymbol\beta$: $\boldsymbol\gamma\odot\mathbf{x}/\sqrt{\operatorname{mean}(x_i^2)+\epsilon}$. It's slightly cheaper and works as well.

    4. The MLP: where most parameters live

    After attention has gathered information into each token's stream, the MLP (feed-forward network) processes each position independently:

    $$\operatorname{MLP}(\mathbf{x}) = W_2\,\operatorname{GELU}(W_1\mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2, \qquad W_1 \in \mathbb{R}^{4d\times d},\ W_2\in\mathbb{R}^{d\times 4d}.$$

    It widens to $4d$ hidden units, applies a nonlinearity, and projects back. GELU, $x\,\Phi(x)$ with $\Phi$ the standard normal CDF (lesson 09), is a smooth ReLU. The MLP has $8d^2 + 5d$ parameters, two-thirds of the block. A useful mental model from interpretability: rows of $W_1$ act like pattern detectors ("this stream looks like a French noun"), and the matching columns of $W_2$ are what gets written to the stream when the pattern fires. Much of a model's factual knowledge appears to be stored in these key–value-like MLP weights. Modern variants (SwiGLU in Llama) use a gated version with three matrices.

    Attention mixes across positions, with weights that depend on the data. The MLP mixes across features, with fixed weights, one position at a time. Alternating them, with residual additions, gives a network that can both route information and transform it.

    5. Positional information

    Lesson 22 proved that attention is permutation-equivariant: without extra information, "dog bites man" and "man bites dog" look the same up to reordering. The causal mask breaks the symmetry a little, but models need explicit positions. There are three standard answers.

    Learned absolute positions (GPT-2, and your tiny GPT)

    Keep a second embedding table $P \in \mathbb{R}^{T_{\max}\times d}$ and add row $t$ to the token embedding at position $t$: $\mathbf{x}^{(0)}_t = E[\text{token}_t] + P[t]$. Simple and effective, but the model can't handle positions beyond $T_{\max}$, because those rows were never trained.

    Sinusoidal (the original transformer)

    A fixed table with pairs of sinusoids at geometrically spaced frequencies $\omega_i = 10000^{-2i/d}$:

    $$PE[p, 2i] = \sin(\omega_i p),\qquad PE[p, 2i+1] = \cos(\omega_i p).$$

    Each pair is a point on a unit circle rotating at its own speed. Low dimensions spin fast (fine position), high dimensions slowly (coarse position), like the hands of a clock. Because $(\sin(\omega(p+k)), \cos(\omega(p+k)))$ is a rotation of $(\sin\omega p, \cos\omega p)$ by angle $\omega k$, the dot product between two positions depends only on their offset (problem 4):

    $$PE[p]\cdot PE[p+k] = \sum_{i}\cos(\omega_i k).$$
    Try it: top, the sinusoidal table for 96 positions (x-axis) and $d = 32$ dimensions (y-axis: the 16 sine dimensions, then the 16 cosine dimensions, fastest frequency at the top of each half), coloured from −1 (pink) to +1 (blue). Bottom, the similarity $PE[p]\cdot PE[q] / (d/2)$ of the selected position $p$ to every $q$. Slide $p$: the curve slides along but keeps exactly the same shape. Similarity depends only on $q - p$.

    Rotary position embedding (RoPE: Llama, most modern LLMs)

    Instead of adding positions to the stream, RoPE rotates the query and key vectors inside every attention layer. Split $\mathbf{q}$ into pairs of coordinates and rotate pair $i$ at position $m$ by angle $m\theta_i$ (block-diagonal rotation matrix $R_m$). Do the same to keys. Rotations satisfy $R_m^\top R_n = R_{n-m}$, so

    $$(R_m\mathbf{q})\cdot(R_n\mathbf{k}) = \mathbf{q}^\top R_m^\top R_n\,\mathbf{k} = \mathbf{q}^\top R_{n-m}\,\mathbf{k}.$$

    The attention score depends on the content of $\mathbf{q}$ and $\mathbf{k}$ and only on their relative position $n - m$. No position vectors ever enter the residual stream.

    Try it: one 2-D pair of a query (orange) and key (blue), shown as originally computed (faint) and after rotation by their positions $m$ and $n$ (solid). Change $m$ and $n$ by the same amount, using the "shift both" slider: the two arrows rotate together, and the score $(R_m\mathbf{q})\cdot(R_n\mathbf{k})$ in the readout doesn't change. Only the offset $n - m$ matters.

    6. The full GPT

    Now stack everything. The input is a batch of token ids, shape $(B, T)$. The output is a distribution over the next token at every position, shape $(B, T, V)$:

    Try it: click any box to see its input/output shapes, parameter count and role. The thick vertical line is the residual stream, and the ⊕ nodes are where branches add back into it. Everything inside the dashed frame repeats $L$ times with separate weights. Shapes use $B$ = batch, $T$ = sequence length, $d$ = width, $V$ = vocabulary, $h$ = heads.

    Because of the causal mask, the logits at position $t$ depend only on tokens $1..t$. A single forward pass on a length-$T$ sequence therefore produces $T$ next-token predictions, one per prefix, and the training loss averages the cross-entropy (lesson 11) over all of them. That parallelism is why transformers train so much faster than RNNs. The workbook tests causality directly: changing a future token must never change an earlier position's logits.

    7. Counting parameters

    Go through one block, writing biases separately:

    PieceWeightsBiases / gains
    LN₁, LN₂—$2d + 2d$
    Attention $W_{QKV}$ ($d \to 3d$)$3d^2$$3d$
    Attention output $W_O$ ($d\to d$)$d^2$$d$
    MLP $W_1$ ($d\to 4d$)$4d^2$$4d$
    MLP $W_2$ ($4d \to d$)$4d^2$$d$
    Block total$12d^2$$13d$

    Then the whole model adds token embeddings $Vd$, position embeddings $T_{\max} d$, the final LayerNorm $2d$, and the output head $dV$ (zero extra if tied to the token embedding):

    $$N = \underbrace{Vd + T_{\max}d}_{\text{embeddings}} + L\,(12d^2 + 13d) + 2d\;\big[+\,dV \text{ if untied}\big].$$

    For large models the $12Ld^2$ term dominates, so a handy rule of thumb is $N \approx 12 L d^2$ non-embedding parameters. Lesson 25 uses $N$ in the scaling laws.

    Try it: load the GPT-2 presets (tied head, $V$ = 50,257, $T_{\max}$ = 1024) and check the totals against the published 124M / 355M / 774M / 1.5B. Then load "tiny GPT", the character-level model you'll train in lesson 24: there the embeddings are negligible and $12Ld^2$ is almost everything. For GPT-2 small, by contrast, the embeddings are almost a third of the model.
    Worked example: GPT-2 small

    $V = 50{,}257$, $T_{\max} = 1024$, $d = 768$, $L = 12$, tied head. Embeddings: $50{,}257\cdot768 + 1024\cdot768 = 38{,}597{,}376 + 786{,}432 = 39{,}383{,}808$. One block: $12\cdot768^2 + 13\cdot768 = 7{,}077{,}888 + 9{,}984 = 7{,}087{,}872$, times 12 is $85{,}054{,}464$. Final LN: $1{,}536$. Total: $124{,}439{,}808$, the famous "124M". The rule of thumb $12Ld^2 = 84{,}934{,}656$ captures the blocks almost exactly.

    You now have the complete architecture of GPT-2, and with RoPE, RMSNorm and SwiGLU swapped in, of Llama. Lesson 24 trains one on Shakespeare. Lessons 28–29 fine-tune exactly this architecture with RL: the "policy" there is this network's next-token softmax.

    8. Problems

    Problem 1
    warm-up

    Apply LayerNorm ($\boldsymbol\gamma = \mathbf 1$, $\boldsymbol\beta = \mathbf 0$, $\epsilon = 0$) to $\mathbf{x} = (2, 4, 6, 12)$. Enter the first and last outputs.

    Solution

    This is $2\times$ the worked example $(1,2,3,6)$. LayerNorm is invariant to scaling the input (for $\epsilon = 0$), so the answer is the same: $(-1.069, -0.535, 0, 1.604)$.

    Problem 2
    warm-up

    How many parameters does one transformer block with $d = 512$ have (biases included)?

    Solution

    $12\cdot512^2 + 13\cdot512 = 3{,}145{,}728 + 6{,}656 = 3{,}152{,}384$.

    Problem 3
    core

    A scalar caricature of depth. 20 layers each have derivative $0.5$. (a) What is the derivative of the whole stack? (b) Now each layer is residual, $y = x + f(x)$ with $f' = 0.05$. What is the derivative of the stack?

    Enter both, comma-separated:

    Solution

    (a) $0.5^{20} \approx 9.54\times10^{-7}$: the first layer gets a millionth of the gradient. (b) $(1 + 0.05)^{20} \approx 2.65$: healthy. Even with tiny branch derivatives, the identity path keeps the product near 1.

    Problem 4
    core · proof

    Prove that for the sinusoidal encoding, $PE[p]\cdot PE[p+k] = \sum_{i=0}^{d/2-1}\cos(\omega_i k)$, independent of $p$. Deduce $\|PE[p]\|^2 = d/2$.

    Hint

    Group the coordinates in pairs; use $\sin a\sin b + \cos a\cos b = \cos(a - b)$.

    Solution

    Pair $i$ contributes $\sin(\omega_i p)\sin(\omega_i(p+k)) + \cos(\omega_i p)\cos(\omega_i(p+k)) = \cos(\omega_i p - \omega_i(p+k)) = \cos(\omega_i k)$. Summing over the $d/2$ pairs gives the claim, with no $p$ anywhere. At $k = 0$ each cosine is 1, so $\|PE[p]\|^2 = d/2$.

    Problem 5
    core · proof

    Let $R(\alpha) = \begin{bmatrix}\cos\alpha & -\sin\alpha\\ \sin\alpha & \cos\alpha\end{bmatrix}$. Show $R(\alpha)^\top R(\beta) = R(\beta - \alpha)$, and conclude that in 2-D RoPE the score $(R(m\theta)\mathbf{q})\cdot(R(n\theta)\mathbf{k})$ depends on $m,n$ only through $n - m$.

    Solution

    $R(\alpha)^\top = R(-\alpha)$ (rotating back), and rotations compose by adding angles: $R(-\alpha)R(\beta) = R(\beta-\alpha)$. You can check this by multiplying out and using the angle-addition formulas. Then $(R(m\theta)\mathbf q)^\top R(n\theta)\mathbf k = \mathbf q^\top R(m\theta)^\top R(n\theta)\mathbf k = \mathbf q^\top R((n-m)\theta)\mathbf k$. In $d$ dimensions RoPE uses a block-diagonal matrix of such rotations, so the same argument applies block by block.

    Problem 6
    core

    Compute the parameter count of GPT-2 medium: $V = 50{,}257$, $T_{\max} = 1024$, $d = 1024$, $L = 24$, tied head.

    Solution

    Embeddings $50{,}257\cdot1024 + 1024\cdot1024 = 51{,}463{,}168 + 1{,}048{,}576 = 52{,}511{,}744$. Blocks: $24\cdot(12\cdot1024^2 + 13\cdot1024) = 24\cdot12{,}595{,}200 = 302{,}284{,}800$. Final LN: $2{,}048$. Total $354{,}823{,}168$, the "355M" model.

    Problem 7
    stretch

    Ignoring biases, what fraction of a block's parameters are in the MLP? If you replaced the MLP by a SwiGLU with three $d\times h$ matrices, what hidden width $h$ keeps the parameter count the same as the $4d$ GELU MLP? Enter the fraction and $h/d$.

    Solution

    MLP: $8d^2$ of $12d^2$, so $2/3$. SwiGLU uses $3dh$ parameters; setting $3dh = 8d^2$ gives $h = \tfrac83 d \approx 2.67d$. That's why Llama's MLP hidden size is about $\tfrac83 d$ rather than $4d$.

    Problem 8
    stretch · conceptual

    (a) A GPT with learned absolute positions is trained with $T_{\max} = 256$. What goes wrong if you feed it 300 tokens? (b) Why does RoPE degrade more gracefully? (c) Why might a model without any position encoding, using only a causal mask, still learn some positional information?

    Solution

    (a) Row 256+ of the position table doesn't exist (an index error), or if you enlarge the table, those rows are untrained random vectors. (b) RoPE has no table. Any position gives a valid rotation, and scores depend on relative offsets, which mostly fall in the trained range for nearby tokens. Very long offsets still use unseen rotation angles, which is why "context extension" methods rescale $\theta$. (c) With a causal mask, token $t$ averages over exactly $t$ tokens. Statistics such as how "diluted" a uniform attention output is reveal $t$, so the network can infer position from them. Such "NoPE" models do learn something, but explicit positions work better.

    9. Quick check

    In a GPT block, which component moves information between different token positions?
    The MLP and LayerNorm act on each position separately, and the residual adds a token's own vector to itself. Only attention mixes positions.
    What is the main advantage of pre-norm ($\mathbf x + f(\operatorname{LN}(\mathbf x))$) over post-norm ($\operatorname{LN}(\mathbf x + f(\mathbf x))$)?
    Pre-norm keeps the "I" in $\prod(I + J_\ell)$ untouched. It actually adds the need for a final LayerNorm ($\operatorname{LN}_f$), because the stream is never normalized.
    Doubling the width $d$ of a large transformer (same $L$, ignoring embeddings) multiplies its parameter count by about:
    $N \approx 12Ld^2$ is quadratic in $d$. Doubling depth $L$ instead only doubles $N$.
    With RoPE, what does the attention score between a query at position 10 and a key at position 7 depend on?
    $(R_m\mathbf q)\cdot(R_n \mathbf k) = \mathbf q^\top R_{n-m}\mathbf k$: content and relative offset only.
