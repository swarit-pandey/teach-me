How this course works

Thirty lessons, bottom-up. You'll start with arrows on a grid. You'll finish by training a GPT on your laptop and then aligning it with the same techniques used for frontier models. Nothing is a black box: every piece gets drawn, derived, and then built by you.

In this lesson

  • See the whole map and how each part feeds the next.
  • Set up the workbooks (one command).
  • Pick a pace and a study method that makes the material stick.

    2. Where we're going

    A taste of the destination. A language model is a function that takes some tokens and outputs a probability for every possible next token. Here are made-up scores ("logits") a model might produce after the prompt "The cat sat on the". Drag the temperature slider to see how sampling changes. Low temperature means the model almost always picks its favourite word; high temperature makes it more adventurous. By lesson 25 you'll know exactly why this works, and you'll have implemented it.

    Try it: slide the temperature toward 0 and the distribution becomes "greedy". Push it up and it flattens toward uniform. The formula is softmax, which you'll derive in lesson 14: $p_i = e^{z_i/T} / \sum_j e^{z_j/T}$.

    4. Setup

    You need Python 3.11+ and Chrome, Safari or Firefox. If you're reading this online, first download the course zip and unzip it. The workbooks run on your own machine. Then, from the course folder:

    ./course setup        # creates .venv with numpy, torch (CPU), pytest
./course list         # all lessons + workbooks
./course open 01      # open lesson 01 in your browser
./course check 01     # grade your workbook 01
./course check 01 -k cosine   # run only tests matching "cosine"

    Each workbook folder contains three files: exercises.py (yours to fill in), test_exercises.py (the grader, so read it when a test fails), and solutions.py (look only after a genuine attempt). Your progress on lessons is saved in the browser. Use "Mark lesson complete" at the bottom of each page, and the home page shows the progress bar.

    Workbooks for lessons 01–18 use only NumPy. PyTorch arrives in lesson 19, after you've built your own autograd engine in lesson 17. That order is deliberate: when you meet loss.backward() you'll know exactly what it does, because you wrote it.

    6. How to make it stick

    • Predict before you play. Before dragging a handle, guess what will happen. The surprise when you're wrong is when the learning happens.
    • Struggle first. Ten honest minutes on a problem before you look at the hint teach you more than reading the solution right away.
    • Explain it out loud. At the end of each lesson, write three sentences explaining the key idea to a colleague. If you can't, you've found the gap.
    • Revisit. Each lesson's quick-check questions make good flashcards. Redo the previous lesson's quiz before starting the next one.
    • Rebuild from memory. After passing a workbook, delete one function and rewrite it without looking.
