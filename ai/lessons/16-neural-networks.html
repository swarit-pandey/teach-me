Neural networks & MLPs

A neural network is not a brain. It is a stack of the two things you already know: a matrix multiply (lessons 01–03) and a cheap bend applied to every number. The bend is the whole trick. Without it, a hundred layers are worth exactly one. With it, a big enough network can draw any shape you like.

By the end you can

  • Write a neuron as "dot product, plus bias, through a nonlinearity", and say what it computes geometrically.
  • Prove that stacked linear layers collapse into one, and explain why nonlinearity fixes this.
  • Explain why a ReLU network is a piecewise-linear function and how that gives universal approximation.
  • Track every tensor shape in a batched forward pass and count a network's parameters.
  • Train a 2-layer network with a hand-derived backward pass, and watch it solve a problem no linear model can.

    1. The neuron: a dot product with a bend

    A single neuron (or unit) takes an input vector $\mathbf{x}\in\mathbb{R}^d$, and computes

    $$a = \phi(\mathbf{w}\cdot\mathbf{x} + b) = \phi(z).$$

    Three pieces. The weights $\mathbf{w}$ and bias $b$ are learned. The number $z = \mathbf{w}\cdot\mathbf{x}+b$ is the pre-activation. The fixed function $\phi$ is the activation or nonlinearity. You have met this already: logistic regression (lesson 14) is one neuron with $\phi = \sigma$.

    Lesson 01 gives you the geometry for free. $\mathbf{w}\cdot\mathbf{x}$ measures how far $\mathbf{x}$ points along $\mathbf{w}$. The set where $z = 0$ is a line (a hyperplane in $d$ dimensions) perpendicular to $\mathbf{w}$. The bias slides that line along $\mathbf{w}$. So a neuron is a soft detector of "which side of a line am I on, and how far?" The activation decides what to report:

    Activation$\phi(z)$$\phi'(z)$Where you see it
    Sigmoid$\dfrac{1}{1+e^{-z}}$$\sigma(z)(1-\sigma(z))$Output of binary classifiers (lesson 14); gates in LSTMs
    Tanh$\tanh z$$1-\tanh^2 z$RNNs (lesson 20); zero-centred cousin of sigmoid: $\tanh z = 2\sigma(2z)-1$
    ReLU$\max(0, z)$$1$ if $z>0$ else $0$The default hidden activation since ~2012
    GELU$z\,\Phi(z)$ ($\Phi$ = Gaussian CDF)smoothTransformers (lesson 23): a smooth ReLU
    Try it: drag the tip of $\mathbf{w}$ and move the bias slider. The shading is the neuron's output $\phi(\mathbf{w}\cdot\mathbf{x}+b)$ at every point $\mathbf{x}$ of the plane. The solid line is $z=0$. Notice that the output only changes along the direction of $\mathbf{w}$: every neuron's output is constant along lines perpendicular to $\mathbf{w}$. Make $\mathbf{w}$ longer and the sigmoid's transition gets sharper. ReLU is zero on one side and a tilted plane (a "ramp") on the other.

    A neuron answers one question about its input: "how much do you point along $\mathbf{w}$, past threshold $-b$?" A layer asks many such questions at once, one per row of a weight matrix. The next layer combines the answers.

    2. Why the bend matters: linear layers collapse

    Put $h$ neurons side by side and you get a layer. Stack their weight vectors as the columns of a matrix $W\in\mathbb{R}^{d\times h}$. We write inputs as row vectors, which is the convention of NumPy and PyTorch (lesson 12): one example per row. Then the whole layer is

    $$\mathbf{a} = \phi(\mathbf{x}W + \mathbf{b}), \qquad \mathbf{x}\in\mathbb{R}^{1\times d},\; W\in\mathbb{R}^{d\times h},\; \mathbf{b}\in\mathbb{R}^{h}.$$

    Now suppose you drop $\phi$ and stack two layers. Expand:

    $$(\mathbf{x}W_1 + \mathbf{b}_1)W_2 + \mathbf{b}_2 \;=\; \mathbf{x}\,\underbrace{(W_1W_2)}_{W_\text{eff}} + \underbrace{(\mathbf{b}_1W_2 + \mathbf{b}_2)}_{\mathbf{b}_\text{eff}}.$$

    That is again a single affine layer. By induction, any number of stacked linear layers equals one linear layer. Depth buys you nothing: a 100-layer linear network can only draw straight decision boundaries, exactly like logistic regression. (In lesson 03's language, a composition of linear maps is a linear map, and its matrix is the product.)

    Worked example: collapsing two layers

    Let $W_1 = \begin{bmatrix}1&2\\0&1\end{bmatrix}$, $\mathbf{b}_1 = (1, 0)$, $W_2 = \begin{bmatrix}1\\-1\end{bmatrix}$, $b_2 = 3$.

    $W_\text{eff} = W_1W_2 = \begin{bmatrix}1\cdot1 + 2\cdot(-1)\\ 0\cdot1+1\cdot(-1)\end{bmatrix} = \begin{bmatrix}-1\\-1\end{bmatrix}$, and $b_\text{eff} = \mathbf{b}_1W_2 + b_2 = (1-0) + 3 = 4$.

    Check with $\mathbf{x} = (2, 1)$. Two-step: $\mathbf{x}W_1 + \mathbf{b}_1 = (2, 5) + (1, 0) = (3, 5)$, then $3 - 5 + 3 = 1$. One-step: $-2 - 1 + 4 = 1$. ✓

    With a nonlinearity in between, the expansion fails: $\phi(\mathbf{x}W_1+\mathbf{b}_1)W_2$ does not factor. The picture below shows what that means. A 2→2 layer maps the plane to the plane. Watch a grid travel through layer 1, then ReLU, then layer 2.

    Try it: press play, or scrub the stage slider: 0 = input, 1 = after the first linear layer, 2 = after ReLU, 3 = after the second linear layer. With ReLU off, every stage is a parallelogram grid: straight, parallel, evenly spaced lines. That is the signature of one affine map (lesson 02), and the readout shows its single matrix. Turn ReLU on: at stage 2 everything outside the positive quadrant is folded onto its edges. Folds are what let later layers carve curved, disconnected regions.

    Depth only helps if there is a nonlinearity between layers. The nonlinearity can be almost anything that isn't affine. ReLU, the simplest possible bend, works great.

    3. ReLU networks are piecewise linear

    Take the simplest case: one input $x\in\mathbb{R}$, one hidden layer of ReLUs, one output.

    $$f(x) = d + \sum_{k=1}^{n} a_k\,\mathrm{relu}(w_k x + c_k).$$

    Each unit is a hinge. It is flat (zero) on one side of the point $x = -c_k/w_k$ and a straight ramp of slope $w_k$ on the other. A weighted sum of hinges is continuous and straight everywhere except at the hinge points, where its slope changes by $a_k w_k$. So $f$ is a continuous piecewise-linear function with at most $n$ kinks. Deeper ReLU nets are still piecewise linear. They just have many more pieces, because each layer folds the pieces of the one before.

    Try it: the dashed curve is the target. The bold curve is $f(x) = d + \sum_k a_k\,\mathrm{relu}(x - c_k)$ with 3 hinge units (here $w_k = 1$, so the hinge sits at $x = c_k$ and $a_k$ is how much the slope changes there). The faint colored lines are the individual units. Fit the target by hand with the sliders, then press best $a$, $d$: it keeps your hinge positions and solves least squares for the output weights (lesson 13). That is exactly what the last layer of a network does. Training moves the hinges too.

    4. Universal approximation, intuitively

    If a sum of hinges can bend wherever you put a hinge, it can trace any continuous curve. Here is the construction (you'll code it in the workbook). Pick knots $x_0 \lt x_1 \lt \dots \lt x_n$ and let $s_k$ be the slope of the straight segment from $(x_k, y_k)$ to $(x_{k+1}, y_{k+1})$. Then

    $$f(x) = y_0 + s_0\,\mathrm{relu}(x - x_0) + \sum_{k=1}^{n-1}(s_k - s_{k-1})\,\mathrm{relu}(x - x_k)$$

    passes through every point and is straight in between. Why: on $[x_0, x_1]$ only the first hinge is on, so $f = y_0 + s_0(x-x_0)$. Each later hinge, once you pass it, changes the slope from $s_{k-1}$ to $s_k$. Now shrink the spacing. A continuous function on a closed interval is uniformly continuous, so the straight-line interpolant's error goes to zero. For a smooth function it shrinks like $1/n^2$.

    Try it: raise the number of hidden units and watch the max error fall. Once $n$ is large enough to resolve the wiggles, doubling $n$ divides the error by about 4 on the smooth targets (the $1/n^2$ rate). Try the "step" target: a continuous net can only approximate a jump with a steep ramp. The error is stuck near the jump in the max sense, but the region where it's bad shrinks.

    The universal approximation theorem (Cybenko 1989, Hornik 1991) says one hidden layer with enough units can approximate any continuous function on a bounded region to any accuracy. It does not say how many units you need (it can be exponential in the input dimension), that gradient descent will find them, or that the result will generalize. In practice depth is far more efficient than width. Each layer can fold space again, so the number of linear pieces can grow exponentially with depth but only linearly with width.

    5. The forward pass, batched, with shapes

    A multi-layer perceptron (MLP) with layer widths $d_0, d_1, \dots, d_L$ is

    $$H_0 = X,\qquad H_\ell = \phi(H_{\ell-1}W_\ell + \mathbf{b}_\ell)\;\;(\ell \lt L),\qquad \text{logits} = H_{L-1}W_L + \mathbf{b}_L.$$

    The last layer has no activation. Its outputs are logits that go into a softmax and cross-entropy (lessons 11, 14). The key to writing this correctly is the batch dimension. Put $N$ examples as the rows of $X \in \mathbb{R}^{N\times d_0}$. One matrix multiply then processes all of them, and the bias row $\mathbf{b}_\ell$ broadcasts down the rows (lesson 12). Row $i$ of every $H_\ell$ depends only on row $i$ of $X$: a batch is just many independent forward passes done in one go, which is what makes GPUs fast.

    Try it: change the batch size $N$ and the layer widths. Inner dimensions must match (the $d$ of $X$ and the rows of $W_1$), and the output keeps the batch dimension. Notice that the parameter count never depends on $N$, but the activation memory does. That is why big batches run out of memory while the model fits fine.
    Worked example: a batched forward pass by hand

    Two examples, $d_0=2$, $d_1=3$, $d_2=2$:

    $$X = \begin{bmatrix}1&2\\-1&0.5\end{bmatrix},\quad W_1 = \begin{bmatrix}1&-1&0.5\\0.5&1&-1\end{bmatrix},\quad \mathbf{b}_1 = (0, 0.5, 0),$$ $$W_2 = \begin{bmatrix}1&-1\\2&0\\-1&1\end{bmatrix},\quad \mathbf{b}_2 = (0, 0.1).$$

    Layer 1. Row 1: $(1\cdot1 + 2\cdot0.5,\; -1 + 2 + 0.5,\; 0.5 - 2) = (2, 1.5, -1.5)$. Row 2: $(-1 + 0.25,\; 1 + 0.5 + 0.5,\; -0.5 - 0.5) = (-0.75, 2, -1)$.

    ReLU. $H_1 = \begin{bmatrix}2&1.5&0\\0&2&0\end{bmatrix}$. Negative entries are zeroed: those units are "off" for that example.

    Layer 2. Row 1: $(2 + 3 + 0,\; -2 + 0 + 0) + (0, 0.1) = (5, -1.9)$. Row 2: $(0 + 4,\; 0) + (0, 0.1) = (4, 0.1)$. Shapes: $(2\times2)(2\times3) \to (2\times3) \to (2\times3)(3\times2) \to (2\times2)$.

    6. Counting parameters

    Layer $\ell$ has a $d_{\ell-1}\times d_\ell$ weight matrix and $d_\ell$ biases:

    $$\#\text{params} = \sum_{\ell=1}^{L} (d_{\ell-1} d_\ell + d_\ell).$$
    Worked example: two real networks

    MNIST classifier 784 → 128 → 10: $784\cdot128 + 128 + 128\cdot10 + 10 = 100{,}352 + 128 + 1{,}280 + 10 = 101{,}770$.

    The MLP inside one GPT-2-small block 768 → 3072 → 768 (lesson 23): $768\cdot3072 + 3072 + 3072\cdot768 + 768 = 4{,}722{,}432$. GPT-2 small has 12 of these, so its MLPs alone hold about 57 million of its 124 million parameters.

    Parameter count drives memory and compute. Each parameter is a float (2–4 bytes). Training with Adam (lesson 18) stores two more numbers per parameter, plus a gradient. A forward pass costs about $2\times$ the parameter count in FLOPs per example, because each weight does one multiply and one add. When you read "7B model", this sum is what's being counted.

    7. Training a 2-layer net on spirals

    The forward pass for a 2-layer classifier, with batch $X\in\mathbb{R}^{N\times D}$ and labels $y$:

    $$Z_1 = XW_1 + \mathbf{b}_1,\quad A_1 = \mathrm{relu}(Z_1),\quad S = A_1W_2 + \mathbf{b}_2,$$ $$L = \tfrac1N\textstyle\sum_i -\log \mathrm{softmax}(S_i)_{y_i}.$$

    The backward pass is lesson 07's matrix calculus applied line by line in reverse. Write $G_S = \partial L/\partial S$ and so on:

    $$\begin{aligned} G_S &= \tfrac1N(\mathrm{softmax}(S) - Y_\text{onehot}) &&\text{lesson 14}\\ G_{W_2} &= A_1^\top G_S, \quad G_{\mathbf{b}_2} = \textstyle\sum_\text{rows} G_S &&\text{matmul rule; broadcast} \Rightarrow \text{sum}\\ G_{A_1} &= G_S W_2^\top\\ G_{Z_1} &= G_{A_1} \odot \mathbb{1}[Z_1 > 0] &&\text{ReLU: a 0/1 mask}\\ G_{W_1} &= X^\top G_{Z_1}, \quad G_{\mathbf{b}_1} = \textstyle\sum_\text{rows} G_{Z_1}. \end{aligned}$$

    A quick shape check catches most mistakes. $G_{W_2}$ must be shaped like $W_2$, $(H\times C)$, and $A_1^\top G_S$ is $(H\times N)(N\times C)$. ✓ Then update every parameter by $\theta \leftarrow \theta - \eta\, G_\theta$ (lesson 06). Writing this by hand for every architecture would be miserable. Lesson 17 automates it.

    The spirals dataset has three interleaved arms. No straight line separates any arm from the others, so softmax regression (a "0 hidden layer" net) gets about 54% accuracy. Watch a hidden layer do better.

    Try it: press play. The background color is the class the network predicts at each point: its decision boundary. Full-batch gradient descent on 300 points runs right in your browser. Then try: (1) hidden units = 0, which is softmax regression, and it can't get past ~55%; (2) hidden = 3 or 5, which is too few hinges to wrap around the arms; (3) a learning rate of 5, which makes the loss jump around or blow up; (4) tanh instead of ReLU, which gives smoother boundaries and slower training. Each change resets the network.

    Why random initialization? If every weight starts at the same value, every hidden unit computes the same thing and receives the same gradient, so they stay identical forever. The network then behaves as if it had a single hidden unit. Random init breaks the symmetry. Its scale matters a lot too. Lesson 18 derives the right one ("He init", which the workbook uses).

    8. Problems

    Problem 1
    warm-up

    A neuron has $\mathbf{w} = (2, -1)$, $b = 0.5$, and input $\mathbf{x} = (1, 3)$. Compute $z$, the ReLU output, and the sigmoid output.

    Enter the sigmoid output:

    Solution

    $z = 2\cdot1 + (-1)\cdot3 + 0.5 = -0.5$. $\mathrm{relu}(-0.5) = 0$: the unit is off. $\sigma(-0.5) = 1/(1+e^{0.5}) \approx 0.3775$.

    Problem 2
    warm-up

    How many parameters does an MLP with widths $3072 \to 512 \to 256 \to 10$ have? (That's a CIFAR-10 image flattened: $32\times32\times3$.)

    Solution

    $3072\cdot512 + 512 = 1{,}573{,}376$; $512\cdot256 + 256 = 131{,}328$; $256\cdot10 + 10 = 2{,}570$. Total $1{,}707{,}274$. Almost all of it sits in the first layer, which is one reason images use convolutions (shared weights) instead.

    Problem 3
    core

    Collapse $W_1 = \begin{bmatrix}2&0\\1&-1\end{bmatrix}$, $\mathbf{b}_1 = (0, 1)$, $W_2 = \begin{bmatrix}1\\3\end{bmatrix}$, $b_2 = -2$ into a single layer $\mathbf{x}W_\text{eff} + b_\text{eff}$. Enter the two entries of $W_\text{eff}$ then $b_\text{eff}$.

    Solution

    $W_1W_2 = (2\cdot1 + 0\cdot3,\; 1\cdot1 + (-1)\cdot3) = (2, -2)$ as a column. $\mathbf{b}_1W_2 + b_2 = 0\cdot1 + 1\cdot3 - 2 = 1$. So the two-layer linear net is just $2x_1 - 2x_2 + 1$.

    Problem 4
    core

    Write the "hat" function $h(x) = \max(0, 1 - |x|)$ (a triangle of height 1 on $[-1,1]$) as $\sum_k a_k\,\mathrm{relu}(x - c_k)$. How many ReLU units do you need?

    Hint

    The slope is 0, then $+1$, then $-1$, then 0. Where does it change, and by how much?

    Solution

    Slope changes by $+1$ at $x=-1$, by $-2$ at $x=0$, by $+1$ at $x=1$: $h(x) = \mathrm{relu}(x+1) - 2\,\mathrm{relu}(x) + \mathrm{relu}(x-1)$. Three units. Shifted and scaled hats are a basis for piecewise-linear functions, which gives another proof of universal approximation in 1-D.

    Problem 5
    core

    A batch of $N = 32$ examples with 100 features goes through a layer with 64 hidden units. (a) What are the shapes of $X$, $W_1$, $Z_1$ and $\partial L/\partial W_1$? (b) How many numbers does the hidden activation $A_1$ hold?

    Solution

    (a) $X: 32\times100$, $W_1: 100\times64$, $Z_1: 32\times64$, and the gradient is always shaped like the parameter: $100\times 64$. (b) $32\cdot64 = 2048$. Activation memory scales with $N$; parameter memory doesn't.

    Problem 6
    core · derivation

    In the backward pass, $G_{\mathbf{b}_2} = \sum_\text{rows} G_S$. Derive this from the chain rule. (Write $S_{ic} = \sum_h A_{ih}W_{hc} + b_c$ and compute $\partial L/\partial b_c$.)

    Solution

    $b_c$ appears in $S_{ic}$ for every example $i$, with $\partial S_{ic}/\partial b_c = 1$, and in no other entry. By the multivariable chain rule, $\partial L/\partial b_c = \sum_i \frac{\partial L}{\partial S_{ic}}\cdot 1 = \sum_i (G_S)_{ic}$. General rule: whatever was broadcast in the forward pass gets summed in the backward pass. Lesson 17 shows this is the same rule as "a reused node accumulates gradients".

    Problem 7
    core

    Find weights for a 2-input network with 2 ReLU hidden units and a linear output that computes XOR on $\{0,1\}^2$: output 1 for $(0,1)$ and $(1,0)$, 0 for $(0,0)$ and $(1,1)$. Why can't a single neuron do it?

    Hint

    Both hidden units can look at $x_1 + x_2$ with different thresholds.

    Solution

    $h_1 = \mathrm{relu}(x_1 + x_2)$, $h_2 = \mathrm{relu}(x_1 + x_2 - 1)$, output $h_1 - 2h_2$. Check: $s = x_1 + x_2 \in \{0, 1, 2\}$ gives $0 - 0 = 0$, $1 - 0 = 1$, $2 - 2 = 0$. ✓ A single neuron thresholds a linear function, so its "1" region is a half-plane. No half-plane contains $(0,1)$ and $(1,0)$ but neither $(0,0)$ nor $(1,1)$, because the two pairs' midpoints coincide at $(\tfrac12, \tfrac12)$.

    Problem 8
    stretch

    A 1-input network with one hidden layer of $n$ ReLUs has at most $n+1$ linear pieces. Now consider a deep 1-D net where every layer is the "tent map" $t(x) = 2\,\mathrm{relu}(x) - 4\,\mathrm{relu}(x - \tfrac12)$ on $[0,1]$ (2 units per layer). How many linear pieces does $t\circ t\circ\cdots\circ t$ ($k$ layers) have? What does that say about depth versus width?

    Solution

    $t$ maps $[0,\frac12]$ up onto $[0,1]$ and $[\frac12,1]$ down onto $[0,1]$. So each application makes the input traverse $[0,1]$ twice, which doubles the number of pieces: $2^k$ pieces from $2k$ units. A single hidden layer would need about $2^k$ units for the same function. Depth can buy exponentially more pieces than width (Telgarsky 2016). This is one rigorous version of "deep beats wide".

    9. Quick check

    You build a 10-layer network but forget the activation functions. Compared with logistic regression on the same features, it can represent…
    $(\mathbf{x}W_1+\mathbf{b}_1)W_2 + \dots$ collapses to $\mathbf{x}W_\text{eff} + \mathbf{b}_\text{eff}$. More parameters, same function class (and a nastier optimization problem).
    You double the batch size from 64 to 128. What happens to the number of parameters?
    Weight shapes are $(d_\text{in}, d_\text{out})$, with no $N$ anywhere. The batch is a dimension of the activations, not of the parameters.
    A network with ReLU hidden units and a linear output, viewed as a function of its input, is…
    Compositions and sums of continuous piecewise-linear functions are continuous piecewise-linear. Kinks appear where some unit switches on or off.
    Why not initialize all weights of a hidden layer to the same constant?
    Symmetric units receive symmetric updates, and nothing ever breaks the tie. Randomness breaks the symmetry.
