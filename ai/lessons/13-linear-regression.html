Part 4 · Machine learning in code

Linear regression from scratch

Your first complete machine-learning model: a model with parameters, a loss that scores them, and two ways to find the best ones. Gradient descent walks downhill; the normal equations jump straight to the bottom. Everything in this lesson reappears inside deep networks. Every layer is a linear model, every training loop is this gradient-descent loop, and badly scaled inputs slow down a transformer for the same reason they slow down a line fit.

By the end you can

  • Write the model $\hat y = X\mathbf{w} + b$ in matrix form and explain the mean-squared-error loss, including why squares (Gaussian MLE).
  • Derive $\nabla L = \tfrac{2}{n}A^\top(A\boldsymbol\theta - \mathbf{y})$ and train with gradient descent.
  • Derive the normal equations two ways, by setting the gradient to zero and by orthogonal projection, and solve them without ever inverting a matrix.
  • Explain, using the condition number, why feature scaling can make gradient descent 100× faster.
  • Fit curves with polynomial features, and measure fit quality with $R^2$.

    1. The model

    You have $n$ examples. Each has $d$ input features $\mathbf{x}_i \in \mathbb{R}^d$ (size, age and location of a house) and a real-valued target $y_i$ (its price). Linear regression predicts with a weighted sum plus an offset:

    $$\hat y_i = \mathbf{w}\cdot\mathbf{x}_i + b = w_1 x_{i1} + \cdots + w_d x_{id} + b.$$

    The weights $\mathbf{w}$ say how much each feature matters, and the bias $b$ is the prediction when all features are zero. Stack the examples as rows of a data matrix $X \in \mathbb{R}^{n\times d}$ and all $n$ predictions come out of one matrix–vector product (lesson 03):

    $$\hat{\mathbf{y}} = X\mathbf{w} + b\,\mathbf{1}.$$

    One trick tidies everything up. Prepend a column of ones to $X$ to get $A = [\mathbf{1}\;X] \in \mathbb{R}^{n\times(d+1)}$, and collect the parameters as $\boldsymbol\theta = (b, w_1, \dots, w_d)$. Then $\hat{\mathbf{y}} = A\boldsymbol\theta$, and the bias is just the weight on a feature that's always 1.

    A layer of a neural network (lesson 16) computes $XW + \mathbf{b}$, which is linear regression with many outputs at once, followed by a non-linearity. The last layer of a regression network is exactly this lesson's model, applied to features the earlier layers learned.

    2. The loss: mean squared error

    For given parameters, the residual $r_i = \hat y_i - y_i$ is how far off prediction $i$ is. We summarize all of them with the mean squared error:

    $$L(\mathbf{w}, b) = \frac1n\sum_{i=1}^n (\hat y_i - y_i)^2 = \frac1n\,\|A\boldsymbol\theta - \mathbf{y}\|^2.$$

    Why squares, and not absolute values or fourth powers? There are three reasons, from shallow to deep:

    • Smoothness. $r^2$ is differentiable everywhere, and $L$ is a quadratic bowl in $\boldsymbol\theta$ with a single minimum and no local traps.
    • Closed form. A quadratic's gradient is linear, so setting it to zero gives a linear system (section 5).
    • Probability. Assume $y_i = \mathbf{w}\cdot\mathbf{x}_i + b + \varepsilon_i$ with Gaussian noise $\varepsilon_i\sim\mathcal N(0,\sigma^2)$ (lesson 09). The negative log-likelihood (lesson 10) is $-\log p(\mathbf{y}) = \frac{n}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2}\sum_i r_i^2$. The first term doesn't depend on $\boldsymbol\theta$, so maximum likelihood = least squares. MSE is the loss you get if you believe the noise is Gaussian. If you instead assume Laplace noise, MLE gives absolute error.
    Try it: drag the data points. Each pink square has side $|r_i|$, so its area is $r_i^2$, and the total pink area is $n\cdot\text{MSE}$. The blue line is the least-squares fit: the line with the smallest total area. Tick "fit by hand" and drag the two orange handles to try to beat it (you can't). Then drag one point far away and watch it pull the whole line. Squares punish big residuals hard, so least squares is sensitive to outliers.

    3. The gradient

    To go downhill we need $\nabla L$ (lessons 06–07). We'll derive it two ways. First, component by component. For one weight $w_j$, the chain rule (lesson 05) on each squared residual gives

    $$\frac{\partial L}{\partial w_j} = \frac1n\sum_i 2\,r_i\,\frac{\partial r_i}{\partial w_j} = \frac2n\sum_i r_i\,x_{ij}, \qquad \frac{\partial L}{\partial b} = \frac2n\sum_i r_i.$$

    Stacking over $j$, $\sum_i r_i x_{ij}$ is the $j$-th entry of $X^\top\mathbf{r}$. So:

    $$\boxed{\;\nabla_{\mathbf w} L = \frac2n X^\top(\hat{\mathbf y} - \mathbf y),\qquad \frac{\partial L}{\partial b} = \frac2n\,\mathbf{1}^\top(\hat{\mathbf y} - \mathbf y)\;}\qquad\text{or together}\qquad \nabla_{\boldsymbol\theta}L = \frac2n A^\top(A\boldsymbol\theta - \mathbf y).$$

    Second, the matrix-calculus way (lesson 07). Expand $L = \frac1n(\boldsymbol\theta^\top A^\top A\boldsymbol\theta - 2\mathbf{y}^\top A\boldsymbol\theta + \mathbf{y}^\top\mathbf{y})$ and use $\nabla_{\boldsymbol\theta}(\boldsymbol\theta^\top M\boldsymbol\theta) = 2M\boldsymbol\theta$ for symmetric $M$ and $\nabla(\mathbf{c}^\top\boldsymbol\theta) = \mathbf{c}$. That gives the same answer, $\frac2n(A^\top A\boldsymbol\theta - A^\top\mathbf y)$. Differentiate once more to get the Hessian:

    $$H = \nabla^2 L = \frac2n A^\top A.$$

    $H$ is constant (the loss is exactly quadratic) and positive semi-definite, since $\mathbf v^\top A^\top A\mathbf v = \|A\mathbf v\|^2 \ge 0$. So the bowl is convex, and any point where the gradient vanishes is a global minimum. $H$'s eigenvalues will control how fast gradient descent goes (section 6).

    Read $X^\top\mathbf r$ as a weighted vote. Each example pushes weight $w_j$ by (its error) × (its feature value). A big error on an example with a big $x_{ij}$ moves $w_j$ a lot. Examples where feature $j$ is zero don't move $w_j$ at all. You'll see the same "error × input" shape in logistic regression (lesson 14) and in every backprop weight gradient (lesson 17).

    4. Gradient descent on the loss surface

    Gradient descent (lesson 06) repeats one update:

    $$\boldsymbol\theta \leftarrow \boldsymbol\theta - \eta\,\nabla L(\boldsymbol\theta) = \boldsymbol\theta - \eta\,\frac2n A^\top(A\boldsymbol\theta - \mathbf y).$$

    In code this is the training loop you'll write a thousand times, in miniature:

    w, b = np.zeros(d), 0.0
for step in range(steps):
    r  = X @ w + b - y                # forward: residuals (n,)
    dw = 2 / n * X.T @ r              # backward: gradient (d,)
    db = 2 / n * r.sum()
    w -= lr * dw;  b -= lr * db       # update

    Because the model has only two parameters when $d=1$, we can draw the whole loss surface over the $(w, b)$ plane as contour lines and watch the path.

    Try it: press play. Left: MSE contours over $(w, b)$, the GD path, and the minimum ★. Right: the line for the current $(w,b)$. Click the contour plot to restart from another point. With raw x (features in $[0, 10]$), the bowl is a long thin valley. A safe learning rate crawls along it, and nudging the rate above $2/\lambda_{\max}$ makes it explode. Switch to standardized x: the contours become circles and GD reaches the minimum in a few steps. Section 6 explains why.

    5. The closed form: normal equations

    Way 1: set the gradient to zero

    The minimum of a convex bowl is where $\nabla L = 0$:

    $$\frac2n A^\top(A\boldsymbol\theta - \mathbf y) = 0 \quad\Longleftrightarrow\quad \boxed{\;A^\top A\,\boldsymbol\theta = A^\top\mathbf y\;}$$

    These are the normal equations: a $(d+1)\times(d+1)$ linear system. If the columns of $A$ are independent (no feature is a linear combination of the others, lesson 03), then $A^\top A$ is invertible and the solution is unique.

    Way 2: project y onto the column space

    Now a picture that needs no calculus. Think of $\mathbf y$ as one point in $\mathbb R^n$, with one axis per example. As $\boldsymbol\theta$ ranges over all values, $A\boldsymbol\theta$ sweeps out the column space of $A$: a $(d+1)$-dimensional flat subspace of $\mathbb R^n$ (lesson 03). Minimizing $\|A\boldsymbol\theta - \mathbf y\|$ means finding the point in that subspace closest to $\mathbf y$. By the geometry of lesson 01, the closest point is the orthogonal projection, and the leftover residual must be perpendicular to the subspace, meaning perpendicular to every column of $A$:

    $$A^\top(\mathbf y - A\boldsymbol\theta) = \mathbf 0 \quad\Longleftrightarrow\quad A^\top A\,\boldsymbol\theta = A^\top\mathbf y.$$

    That's the same equation. It is lesson 01's $\operatorname{proj}_{\mathbf a}\mathbf b = \frac{\mathbf a\cdot\mathbf b}{\mathbf a\cdot\mathbf a}\mathbf a$, generalized from a line to a subspace. The "normal" in the name is that orthogonality.

    Try it: three data points at $x = 1, 2, 3$ make $\mathbf y \in \mathbb R^3$, one axis per data point. The shaded plane is the column space of $A$, spanned by $\mathbf 1 = (1,1,1)$ and $\mathbf x = (1,2,3)$, the set of every prediction a line can make. Move the $y_i$ sliders. The fitted predictions $\hat{\mathbf y}$ are always the foot of the perpendicular from $\mathbf y$, and the readout confirms $A^\top\mathbf e = 0$. Rotate the view to convince yourself the dashed residual really is perpendicular to the plane. When the three points lie on a line, $\mathbf y$ sits in the plane and the residual vanishes.
    Worked example: four points

    Fit a line to $(1,1), (2,3), (3,2), (4,5)$. With $A = [\mathbf 1\;\mathbf x]$:

    $$A^\top A = \begin{bmatrix} n & \sum x_i \\ \sum x_i & \sum x_i^2\end{bmatrix} = \begin{bmatrix} 4 & 10 \\ 10 & 30\end{bmatrix},\qquad A^\top\mathbf y = \begin{bmatrix}\sum y_i \\ \sum x_i y_i\end{bmatrix} = \begin{bmatrix} 11 \\ 33\end{bmatrix}.$$

    The determinant is $4\cdot30 - 10\cdot10 = 20$. By Cramer's rule (fine for 2×2), $b = (30\cdot11 - 10\cdot33)/20 = 0$ and $w = (4\cdot33 - 10\cdot11)/20 = 22/20 = 1.1$. So $\hat y = 1.1x$.

    The predictions are $(1.1, 2.2, 3.3, 4.4)$ and the residuals $\mathbf y - \hat{\mathbf y} = (-0.1, 0.8, -1.3, 0.6)$. Check orthogonality: they sum to $0$ (perpendicular to $\mathbf 1$), and $1(-0.1) + 2(0.8) + 3(-1.3) + 4(0.6) = 0$ (perpendicular to $\mathbf x$). ✓ MSE $= (0.01 + 0.64 + 1.69 + 0.36)/4 = 0.675$.

    Solving it in practice: never invert

    The textbook formula $\boldsymbol\theta = (A^\top A)^{-1}A^\top\mathbf y$ is for derivations. In code, use np.linalg.solve(A.T @ A, A.T @ y). It does one LU factorization instead of computing a full inverse, and it is faster and more accurate. Better still is np.linalg.lstsq(A, y), which uses an orthogonal factorization (QR or SVD, lesson 04) of $A$ itself. Forming $A^\top A$ squares the condition number (section 6), so a problem that's merely touchy becomes hopeless in floating point. The workbook has you write the QR route yourself.

    How good is the fit? $R^2$

    MSE has units (dollars squared), which makes it hard to read on its own. The coefficient of determination compares it with the dumbest baseline, always predicting the mean $\bar y$:

    $$R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2}.$$

    $R^2 = 1$ is a perfect fit. $R^2 = 0$ is no better than the mean. On new data, $R^2$ can go negative. In the worked example, $\sum(y_i - \bar y)^2 = 8.75$ and $\sum r_i^2 = 2.7$, so $R^2 = 1 - 2.7/8.75 \approx 0.691$: the line explains about 69% of the variance in $y$.

    6. Feature scaling and the condition number

    Why did GD crawl with raw features? Near the minimum $\boldsymbol\theta^*$, write the error as $\boldsymbol\delta = \boldsymbol\theta - \boldsymbol\theta^*$. Since $\nabla L = H\boldsymbol\delta$ exactly for a quadratic, one GD step gives

    $$\boldsymbol\delta \leftarrow (I - \eta H)\,\boldsymbol\delta.$$

    Decompose $\boldsymbol\delta$ along the eigenvectors of $H$ (lesson 04). Along an eigenvector with eigenvalue $\lambda$, each step multiplies the error by $(1 - \eta\lambda)$. Two consequences:

    • Stability needs $|1 - \eta\lambda| \lt 1$ for every eigenvalue, so $\eta \lt 2/\lambda_{\max}$. The steepest direction caps the step size.
    • Speed along the flattest direction is $1 - \eta\lambda_{\min} \ge 1 - 2\lambda_{\min}/\lambda_{\max}$. The number of steps needed grows like the condition number $\kappa = \lambda_{\max}/\lambda_{\min}$.

    Geometrically, $\kappa$ is how elongated the contour ellipses are: their axis lengths scale like $1/\sqrt{\lambda}$. A large $\kappa$ means a long thin valley. The step size you'd like for crossing the valley is far too large for walking down its length.

    Worked example: why raw features are slow

    One feature, uniformly spread over $[0, 10]$, so $\bar x = 5$ and $\overline{x^2} = 100/3$. With $A = [\mathbf 1\;\mathbf x]$,

    $$H = \frac2n A^\top A = 2\begin{bmatrix} 1 & \bar x \\ \bar x & \overline{x^2}\end{bmatrix} = 2\begin{bmatrix} 1 & 5 \\ 5 & 33.3\end{bmatrix}.$$

    Its eigenvalues are about $68.2$ and $0.489$, so $\kappa \approx 139$ and the largest stable learning rate is $2/68.2 \approx 0.029$.

    Center the feature ($x - \bar x$). The off-diagonal $\bar x$ becomes 0 and $H = 2\,\mathrm{diag}(1, \operatorname{Var}x) = \mathrm{diag}(2, 16.7)$, so $\kappa = 8.3$. Standardize it ($(x-\bar x)/s$). Now $H = 2I$, $\kappa = 1$, and the contours are circles. With $\eta = 1/2$, $I - \eta H = 0$: GD lands on the minimum in one step.

    Compute the mean and standard deviation on the training set only, then apply those same numbers to validation and test data (lesson 15). Recomputing them on test data leaks information and quietly changes what the model sees. The workbook's Standardizer has separate fit and transform for this reason. It also has unscale, which converts the learned weights back to raw units so you can interpret them.

    This is the first reason deep learning normalizes everything: inputs, activations (BatchNorm, LayerNorm, lesson 18), and even gradients (Adam's per-parameter scaling is a cheap diagonal fix for bad conditioning). Different scales across directions in parameter space mean slow, unstable training, whether the model has 2 parameters or 2 billion.

    7. Polynomial features: curves with a linear model

    "Linear" regression means linear in the parameters, not in the input. Nothing stops us from inventing new features. Replace $x$ with $(x, x^2, \dots, x^p)$ and fit

    $$\hat y = w_1 x + w_2 x^2 + \cdots + w_p x^p + b.$$

    It's still $A\boldsymbol\theta$ with a bigger $A$, so the normal equations, GD and everything above still apply. The model can now bend.

    Try it: raise the degree. Training error falls every time, because each extra feature can only help the fit. At degree 7 with 8 points the curve passes through every point exactly (zero error) and swings wildly in between. Would you trust its prediction at $x = 9.5$? Drag a point and watch the high-degree curve react everywhere. Lesson 15 turns this unease into a measurement.

    Two practical notes. First, powers of $x$ have wildly different scales ($10$ vs $10^7$ for $x=10$, $p=7$), and they are nearly collinear, since $x^6$ and $x^7$ look alike. That gives a terribly conditioned $A$. Rescale $x$ to $[-1, 1]$ before taking powers, and solve with lstsq/QR. The figure does both. Second, with $d$ input features, all degree-2 terms (squares and pairwise products) already number $d(d+1)/2$. Hand-crafted feature expansion doesn't scale. That's the opening for neural networks, which learn their features (lesson 16).

    8. Problems

    Problem 1
    warm-up

    Fit $\hat y = wx + b$ to the points $(0, 1), (1, 2), (2, 4)$ by least squares. Enter $w, b$.

    Hint

    For one feature the normal equations reduce to $w = \sum(x_i-\bar x)(y_i - \bar y) / \sum (x_i - \bar x)^2$ and $b = \bar y - w\bar x$ (problem 3).

    Solution

    $\bar x = 1$, $\bar y = 7/3$. Deviations: $x - \bar x = (-1, 0, 1)$ and $y - \bar y = (-4/3, -1/3, 5/3)$. Then $w = (4/3 + 0 + 5/3)/2 = 3/2$ and $b = 7/3 - 3/2 = 5/6 \approx 0.833$.

    Problem 2
    warm-up

    What is the training MSE of the fit in problem 1?

    Solution

    Predictions: $5/6, 7/3, 23/6$. Residuals $y - \hat y = (1/6, -1/3, 1/6)$. Squares: $1/36 + 4/36 + 1/36 = 6/36 = 1/6$. Divide by $n=3$: $1/18 \approx 0.0556$. Note that the residuals sum to 0 and are orthogonal to $\mathbf x = (0,1,2)$: $0 - 1/3 + 1/3 = 0$ ✓.

    Problem 3
    core · derivation

    For a single feature, write out the two normal equations and solve them to show $b = \bar y - w\bar x$ and $w = \dfrac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sum_i (x_i - \bar x)^2} = \dfrac{\operatorname{Cov}(x,y)}{\operatorname{Var}(x)}$. What does the first equation say about the fitted line and the point $(\bar x, \bar y)$?

    Solution

    The first row of $A^\top A\boldsymbol\theta = A^\top\mathbf y$ is $nb + w\sum x_i = \sum y_i$. Divide by $n$: $b + w\bar x = \bar y$. So the fitted line always passes through the centroid $(\bar x, \bar y)$, and $b = \bar y - w\bar x$. The second row is $b\sum x_i + w\sum x_i^2 = \sum x_i y_i$. Substitute $b$: $w(\sum x_i^2 - n\bar x^2) = \sum x_i y_i - n\bar x\bar y$. Both sides are $n\times$ the (biased) variance and covariance, since $\sum x_i^2 - n\bar x^2 = \sum(x_i-\bar x)^2$ and $\sum x_iy_i - n\bar x\bar y = \sum (x_i-\bar x)(y_i-\bar y)$.

    Problem 4
    core

    Starting from $w = b = 0$ on the data of problem 1, take one gradient-descent step with $\eta = 0.1$. Enter the new $w, b$.

    Solution

    At zero, the residuals are $\hat y - y = -\mathbf y = (-1, -2, -4)$. Then $\partial L/\partial w = \frac23\sum r_i x_i = \frac23(0 - 2 - 8) = -20/3$, and $\partial L/\partial b = \frac23(-7) = -14/3$. The step gives $w = 0.1\cdot 20/3 \approx 0.667$ and $b = 0.1\cdot14/3 \approx 0.467$.

    Problem 5
    core

    Using the worked example of section 6 (one raw feature uniform on $[0,10]$, $H = 2\begin{bmatrix}1&5\\5&33.3\end{bmatrix}$), what is the largest learning rate for which GD converges? What about after centering only?

    Solution

    $\eta \lt 2/\lambda_{\max}$. The eigenvalues of $\begin{bmatrix}1&5\\5&100/3\end{bmatrix}$ are $\frac{34.33 \pm \sqrt{32.33^2 + 100}}{2} \approx 34.09$ and $0.244$. Times 2: $\lambda_{\max} \approx 68.18$, so $\eta \lt 0.0293$. After centering, $H = \mathrm{diag}(2, 2\cdot 8.33)$, $\lambda_{\max} = 16.7$ and $\eta \lt 0.12$, four times larger. Standardizing allows $\eta \lt 1$.

    Problem 6
    core · proof

    Let $P = A(A^\top A)^{-1}A^\top$ (the "hat matrix", since $\hat{\mathbf y} = P\mathbf y$). Show that (a) $P^2 = P$ and $P^\top = P$, (b) $I - P$ maps $\mathbf y$ to the residual, and $A^\top(I-P) = 0$, and (c) if $A$ contains a column of ones, the residuals sum to zero.

    Solution

    (a) $P^2 = A(A^\top A)^{-1}(A^\top A)(A^\top A)^{-1}A^\top = P$. Projecting twice changes nothing. $P^\top = P$ because $(A^\top A)^{-1}$ is symmetric. (b) $\mathbf y - \hat{\mathbf y} = (I - P)\mathbf y$, and $A^\top - A^\top A(A^\top A)^{-1}A^\top = A^\top - A^\top = 0$. (c) The row of $A^\top(I-P)\mathbf y = 0$ that belongs to the ones column reads $\mathbf 1^\top\mathbf e = \sum_i e_i = 0$.

    Problem 7
    core · conceptual

    You add a new feature to a linear regression (even pure random noise) and refit. Prove that the training MSE cannot go up. Why does this make training $R^2$ a poor way to choose features?

    Solution

    The old solution is still available: set the new weight to 0. The new minimum is over a strictly larger set of parameter values, so it's $\le$ the old minimum. In projection terms, the column space only grows, so $\mathbf y$ can only get closer to it. Training $R^2$ therefore always rewards more features, including useless ones. You need held-out data to tell real improvement from memorizing noise (lesson 15).

    Problem 8
    stretch

    With $d = 10$ input features, how many features does a full degree-2 polynomial expansion have (all $x_j$, all $x_j^2$ and all products $x_jx_k$ with $j\lt k$, excluding the constant)?

    Solution

    $d$ linear terms, $d$ squares, $\binom d2 = 45$ products: $10 + 10 + 45 = 65 = d + d(d+1)/2$. Degree $p$ in $d$ variables gives $\binom{d+p}{p} - 1$ features, which explodes combinatorially. For $d=784$ (MNIST pixels) and $p=2$ it's already 308,504.

    Problem 9
    stretch · derivation

    Show that with standardized features (each column of $X$ has mean 0 and variance 1) that are also mutually uncorrelated, the Hessian is $H = 2I$, and that GD with $\eta = 1/2$ reaches the exact minimum in a single step from any starting point.

    Solution

    $\frac1n A^\top A$ has entries $\frac1n\sum_i 1 = 1$, $\frac1n\sum_i x_{ij} = 0$ (mean 0), $\frac1n\sum_i x_{ij}^2 = 1$ (variance 1), and $\frac1n\sum_i x_{ij}x_{ik} = 0$ (uncorrelated). So it's $I$, and $H = 2I$. The error update is $\boldsymbol\delta \leftarrow (I - \eta H)\boldsymbol\delta = (1 - 2\eta)\boldsymbol\delta$, which is $0$ for $\eta = 1/2$. Decorrelating features as well ("whitening", via PCA, lesson 04) makes the bowl perfectly round.

    9. Quick check

    Why does minimizing MSE correspond to maximum likelihood?
    $-\log \mathcal N(y\mid\hat y,\sigma^2) = \tfrac12\log 2\pi\sigma^2 + (y-\hat y)^2/2\sigma^2$. Summing over examples and dropping constants leaves the squared error. A different noise model gives a different loss: Laplace noise gives absolute error.
    At the least-squares solution, the residual vector $\mathbf e = \mathbf y - A\boldsymbol\theta$ is…
    That's the normal equations, $A^\top\mathbf e = 0$. It's zero only if $\mathbf y$ lies exactly in the column space. It's generally not orthogonal to $\mathbf y$ itself; it's orthogonal to $\hat{\mathbf y}$.
    GD on raw features is slow. You standardize the features and it converges in a few steps. What changed?
    The loss was convex already. Scaling changes the shape of the bowl, from a long valley to a round dish. Since $\eta \lt 2/\lambda_{\max}$ while progress depends on $\lambda_{\min}$, the ratio $\kappa$ sets the number of steps.
    Which is the right way to compute the least-squares weights in NumPy?
    (b) is mathematically right but numerically worse: it forms an explicit inverse and squares the condition number. (c) fails, because $A$ is $n\times(d+1)$ and not square. (d) is element-wise division of a vector by a matrix. Broadcasting will happily give you nonsense (lesson 12).
